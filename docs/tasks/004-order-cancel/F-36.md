## 1. 改变范围

- 本卡交付的用户可感知行为（只能一个）：坐席可为已接管会话发起取消，客户确认后自动提交；工作台与客户 UI 可验收。
- 涉及层：后端（工作台路由）、前端 apps/workspace、evals、走查

- 本次改变：
- 新增 `POST /workspace/conversations/{id}/cancellations`：本人接管 + `verified_order_ids`。
- 客户聊天/订单页出现同一张确认卡片；客户确认后 Workflow 自动提交，坐席无提交按钮。
- 工作台会话详情增加取消区（状态、订单、待办、结果）。
- 客户列表/聊天卡片/确认/结果 UI 四档宽度与可访问性收口。
- 评测与岗位走查：列表入口、聊天入口、订单号兜底、超时恢复、未知转人工。
- 测试：`tests/integration/test_order_cancel_AC_69.py`（待创建）、`tests/integration/test_order_cancel_AC_71.py`（待创建）、`tests/integration/test_order_cancel_AC_72.py`（待创建）；`apps/workspace/tests/CancellationPanel.test.tsx`（待创建）。

- 本次不改变：
- 001 队列/接管/回复/关闭。
- 客户自助取消路径（F-31）。

- 不在本卡范围：坐席代确认、坐席二次提交、主管审批。
