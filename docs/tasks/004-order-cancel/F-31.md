## 1. 改变范围

- 本卡交付的用户可感知行为（只能一个）：客户在列表/聊天卡片点“取消订单”，确认后只提交一次；拒绝/过期不提交。
- 涉及层：后端（任务/确认/结果）、迁移、前端 apps/chat、契约

- 本次改变：
- 迁移 `0014_order_cancel.py`：任务新增 `requested_by_type`、`requested_by_id`、`confirmed_at`、`confirmation_source`、`confirmed_by_id`；部分唯一索引 `uq_cancellation_active_order`。
- 新增 `POST /customer/cancellations`、`/confirm`、`/decline`；24 小时确认有效期。
- 确认卡片消息/结果卡；客户确认后 Workflow 自动提交，结果文案复用 `render_result`。
- 测试：`tests/integration/test_order_cancel_AC_60.py`（待创建）、`tests/integration/test_order_cancel_AC_61.py`（待创建）、`tests/integration/test_order_cancel_AC_62.py`（待创建）；`apps/chat/tests/CancelCard.test.tsx`（待创建）。

- 本次不改变：
- 坐席发起（F-36）。
- 交接单取消上下文（F-35）。
- 003 订单查询路径。

- 不在本卡范围：退款、已发货拦截、部分取消、坐席代确认。
