## 1. 改变范围

- 本卡交付的用户可感知行为（只能一个）：不可取消订单给原因；他人/跨租户查无；重复/并发只提交一次。
- 涉及层：后端（Policy/归属/并发）、测试、契约

### 1.1 触点（文件 → 改什么）

| 文件 | 改动 |
|---|---|
| `backend/conversations/cancellation_access.py` | 新增客户/坐席 actor 与归属闸门：坐席要求同租户 + 本人接管 + `HUMAN_ACTIVE` + 交接单 `ACTIVE` + 订单在已核验清单；代确认抛 403 |
| `backend/conversations/customer_cancellations.py` | 确认/拒绝接入确认闸门；发起加 savepoint，唯一索引冲突回读已有任务或 409 |
| `tests/integration/test_order_cancel_AC_64.py` | 四种不可取消状态的原因、零 OMS 写与不暴露内部原因码 |
| `tests/integration/test_order_cancel_AC_65.py` | 客户越权矩阵走 HTTP；坐席闸门按 S-2 seam 直驱 |
| `tests/integration/test_order_cancel_AC_66.py` | 重复确认、并发确认、并发发起、唯一索引冲突回读、终态后重新发起 |
| `tests/integration/workspace_support.py` | 工作台测试清理补取消任务，避免跨文件污染 |
| `docs/specs/004-order-cancel/design.md` | 5.2 补闸门落点与并发兜底澄清 |
| `docs/tasks/004-order-cancel/F-33.md` | 本卡（DoR/触点/判定表/证据） |

- 本次改变：
- 资格判定接入 Policy Engine；备货/发货/送达/已取消返回原因，零 OMS 写。
- 客户/坐席归属闸门：他人/跨租户 404；坐席仅 `verified_order_ids`。
- 活跃任务唯一索引冲突处理：回读已有任务或 409。
- 确认/拒绝条件更新与重复请求幂等。
- 测试：`tests/integration/test_order_cancel_AC_64.py`、`tests/integration/test_order_cancel_AC_65.py`、`tests/integration/test_order_cancel_AC_66.py`。

- 本次不改变：
- 取消结果文案（F-31/F-34）。
- 交接单取消上下文（F-35）。

- 不在本卡范围：主管审批、金额阈值、跨账号代客取消。
