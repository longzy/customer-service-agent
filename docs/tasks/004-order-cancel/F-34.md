## 1. 改变范围

- 本卡交付的用户可感知行为（只能一个）：提交超时/未知先核实、不重复提交；取消全链路可审计、可追溯。
- 涉及层：后端（Workflow/审计/Trace）、测试

- 本次改变：
- 接入 `SUBMIT_UNKNOWN` 恢复：最多 3 次退避、幂等键查询、并发保护。
- 已受理后刷新到 CANCELLED/REJECTED；不把 ACCEPTED 当永久终态。
- 补已受理任务在“我的订单”列表的刷新入口（结果卡关闭后仍可看到最终状态）。
- 审计事件 `cancellation.requested/confirmed/abandoned/submitted/result`；字段与白名单按 design 5.1。
- Tool Gateway 记录资格/提交/结果；同一 `trace_id` 串联。
- 测试：`tests/integration/test_order_cancel_AC_67.py`（待创建）、`tests/integration/test_order_cancel_AC_70.py`（待创建）。

- 本次不改变：
- 资格/越权（F-33）。
- 交接单取消上下文（F-35）。

- 不在本卡范围：真实 OMS、支付退款、审计归档。
