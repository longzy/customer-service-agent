## 1. 改变范围

- 本卡交付的用户可感知行为：无（内部模块搬迁；HTTP/DB/Tool/Workflow 行为不变）。
- 涉及层：后端模块、测试 import、迁移脚本、Trace 脚本。

- 本次改变：
  - `settings`、`db`、`models`、`observability` 迁到 `backend/platform/`。
  - `Identity`/`ACCOUNTS`/session 迁到 `backend/identity/`（纯身份，不依赖 FastAPI）。
  - FastAPI 中间件 `resolve_identity`/`current_identity` 拆到 `backend/api/auth_web.py`。
  - `orders`/`cancellation`/`errors` 迁到 `backend/domain/`。
  - 更新 `api`/`tools`/`workflows`/`agent_runtime`/`tests`/`migrations`/`scripts` 的 import。
  - 清理 `scripts/import-baseline.txt` 的 R1 条目。
- 本次不改变：
  - 不改路由、状态码、响应体、Cookie/session 语义。
  - 不改 DB schema、Alembic 迁移、Tool 契约、Policy、Workflow 状态机。
  - 不迁移 `mock_oms`、不实现 `OmsPort`（T-24/T-25）。

## 2. 任务级决策

### 2.1 需人类决策

无。目标目录与依赖规则已在 design 第 2、3 节批准。

### 2.2 声明的 seam

| ID | 内部接口 | 为什么测试直接驱动它 |
|---|---|---|
| S-1 | `backend.identity.Identity` / `get_session` | tools/workflows/api 的授权主体，import 迁移后必须保持同一实例语义 |
| S-2 | `backend.api.auth_web.resolve_identity` / `current_identity` | Cookie → request.state.identity 的行为不变 |
| S-3 | `backend.platform.models.Base.metadata` | 移动 models 后 DB schema 必须不变 |
| S-4 | `backend.platform.observability` 的 TraceSink | tools/workflows 的 Trace 行为不变 |

### 2.3 实现者自行决定

| ID | 问题 | 决定 | 理由 | 返工代价 |
|---|---|---|---|---|
| D-1 | identity 文件粒度 | 纯身份放 `backend/identity/__init__.py` | 体量小；避免为 75 行拆多文件 | 小 |
| D-2 | 是否留旧路径 shim | 不留；一次性更新全部 import | 避免 T-26 再删一次；`check-imports` 可验证 | 中 |
| D-3 | `resolve_identity` 归属 | `backend/api/auth_web.py` | FastAPI 依赖留在 HTTP 层，identity 保持纯 | 小 |
| D-4 | 迁移方式 | `git mv` + 机械替换 + 全量测试 | 保持文件历史，减少手改遗漏 | 中 |

### 2.4 判定表与失败矩阵

| AC | 主路径 | 非法输入 | 权限 | 下游故障 | 并发/重复 | 幂等 | 配置门禁 |
|---|---|---|---|---|---|---|---|
| AC-23 | `check-imports --strict` 中 R1 条目为 0 | import 旧路径 → 检查器失败 | 不适用 | 不适用 | 不适用 | 不适用 | 现有 430 测试与 OpenAPI/DB 快照不变 |
