### 2.2 实现者自行决定

| ID | 问题 | 决定 | 理由 | 返工代价 |
|---|---|---|---|---|
| D-1 | 会话接口形状 | `POST /session`（body: `account_id`）、`DELETE /session`、`GET /session`（返回当前身份或 401） | 与设计一致，且便于测试 | 小 |
| D-2 | Cookie 属性 | `HttpOnly`、`SameSite=Lax`、开发期不设 `Secure`；TTL 8 小时 | 本机 HTTP 开发可用，属性将来可加 `Secure` | 小 |
| D-3 | 中间件失败行为 | 受保护路由无有效会话返回 401，不重定向（前端负责跳登录页） | API 与页面职责分离，便于前端处理 | 小 |
