# 任务执行卡：T-20 会话安全基线

- 依据：`docs/specs/001-order-cancel/requirements.md` 第 2 节 AC-21、`docs/specs/001-order-cancel/design.md` 第 13 节、`docs/process/standards.md` STD-SEC-02/03/06
- 绑定验收：AC-21
- 状态：已完成
- 变更级别：T3（涉及会话与权限边界）
- 设计引用：Cookie 属性、跨站写请求与密钥扫描规则以 `design.md` 第 13 节为准，本卡不重复。

## 1. 改变范围

- 本卡交付的用户可感知行为：非开发环境会话 Cookie 带 `Secure`；跨站来源的写请求被拒绝且无副作用。
- 涉及层：后端 / 脚本 / CI 配置（跨层不作为拆分理由）。

- 本次改变：
  - `settings.py` 增加 `cookie_secure` 覆盖项与 `secure_cookie` 派生属性。
  - `session_routes.py` 按 `secure_cookie` 设置 Cookie。
  - 新增 `backend/api/csrf.py`：对 `POST/PUT/PATCH/DELETE` 校验 `Origin` 与 `Host`，命中白名单或缺失 `Origin` 时放行。
  - 新增 `scripts/check-secrets.py`，接入 pre-commit 与 `verify.sh`。
- 本次不改变：
  - 登录方式、会话 TTL、身份来源与租户模型。
  - 错误响应的全局封套（仍为 `{"detail"}`，登记为 STD-API-02 遗留）。
  - `/_admin` 的独立鉴权（登记为 STD-SEC-05 遗留）。

## 2. 任务级决策

### 2.1 需人类决策

| ID | 问题 | 选项与代价 | 建议 | 答复 |
|---|---|---|---|---|
| Q-1 | `Secure` 在生产之外是否强制？ | 全环境强制：本机 HTTP 登录失效；仅非开发环境强制：本机可用、共享环境加密 | 仅非开发环境强制 | 已答复（2026-11-16）：采用建议 |
| Q-2 | 缺 `Origin` 的写请求是否放行？ | 拒绝：命令行与内部调用全部失败；放行：浏览器跨站写请求必带 `Origin`，风险有限 | 放行并记录 | 已答复（2026-11-16）：放行 |
| Q-3 | 密钥扫描用什么形式？ | 引入 gitleaks：需要额外依赖；仓库内正则脚本：零依赖、可测 | 先正则脚本 + CI，gitleaks 作为后续增强 | 已答复（2026-11-16）：先脚本 |

### 2.2 声明的 seam

| ID | 内部接口 | 为什么测试直接驱动它 |
|---|---|---|
| S-1 | HTTP `/session` 的 `Set-Cookie` | Cookie 属性只能从响应头观测 |
| S-2 | 全局中间件 `verify_origin` | 跨站拒绝发生在路由之前，需从状态码与副作用观测 |
| S-3 | `scripts/check-secrets.py` 的 `scan_text` | 扫描规则需要反向验证，避免“加注释就漏报” |

### 2.3 实现者自行决定

| ID | 问题 | 决定 | 理由 | 返工代价 |
|---|---|---|---|---|
| D-1 | 来源比较方式 | 比较 `Origin` 的 netloc 与 `Host`；代理改写 Host 时靠白名单 | 不依赖协议与端口；代理部署必须配置 `ALLOWED_ORIGINS` | 低 |
| D-2 | 白名单格式 | `ALLOWED_ORIGINS` 逗号分隔，默认空 | 与现有 settings 风格一致 | 低 |
| D-3 | 拒绝响应格式 | 403 + `{"detail": "跨站请求被拒绝"}` | 与现有错误风格一致，统一封套留给 STD-API-02 | 低 |
| D-4 | 扫描范围 | `git ls-files` 的文本文件，跳过二进制与锁文件 | 覆盖入库内容，避免噪声 | 低 |

### 2.4 失败矩阵

| AC | 主路径 | 非法输入 | 权限 | 下游故障 | 并发/重复 | 幂等 | 配置门禁 |
|---|---|---|---|---|---|---|---|
| AC-21 | 同源写请求通过 | 跨源 `Origin` → 403 | 不适用（认证前策略） | 不适用 | 不适用 | 重复登录仍换新 sid | `COOKIE_SECURE`、`ALLOWED_ORIGINS` |
