反向验证：

- 把 `SessionGate` 的 `if (!session)` 改成 `if (session)`，未登录跳转用例立即失败（`expected spy to be called with ['/login']`）。
- 把 `settings.test_accounts_enabled` 改成恒为 `True`，生产门禁用例失败（`assert 200 == 404`）。

评审修复（第二轮）：

- 测试账号改为环境白名单（`development`/`test`），`production`、`prod`、空值一律关闭，`POST /session` 一并门禁。
- `SessionGate` 只在 401 时跳登录；500 与网络错误显示“请求未完成，请重试”，不再误判为未登录。
- 退出检查 `response.ok`，失败提示且不跳转；补退出点击、退出失败、500、空账号列表、请求体账号断言。
- 登录页补充加载完成状态与“无可用账号”提示。
- 设计文档同步：去掉角色展示，明确切换账号 = 退出后重新登录。
- 环境变量默认改为 `production`，测试通过 conftest 显式切到 `development`；`.env.example` 增加 `ENVIRONMENT=development`。
- 登录页补“加载中…”提示；退出失败后的“重试”改调退出而不是重新加载。
