### 4.1 评审返工（有条件通过 → 修复）

| 问题 | 处理 |
|---|---|
| `IntentError` 未映射，非法模型输出返回 500 | 路由捕获 `(ModelError, IntentError)` 统一 503，并保留用户消息 |
| 最近订单分支未捕获网关错误 | 两个查询分支共用 try，故障转用户可见文案 |
| `INTERNAL_ERROR` 被当作可见回复，谎称“已转人工” | 按 `visible` 与错误码映射；内部错误回通用文案 |
| 真实 SQL 仓储零测试 | 新增 `test_conversation_repository.py`：落库、同 trace、跨用户/跨租户 404、级联删除 |
| DB 不可用时集成用例失败而非跳过 | 新增 `db_utils.db_available`，两个集成文件按可用性 skip |
| 用户消息在模型调用后才提交 | 编排开始即提交用户消息，模型失败不丢输入 |
| 人工/取消分支冒充已执行 | 改为“将在后续版本开放”，不再宣称已转接 |
| AC 绑定错标 | 401 改 AC-20，越权改 AC-02，模型失败改基座豁免 |
