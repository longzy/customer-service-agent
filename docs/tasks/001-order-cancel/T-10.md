### 4.1 评审返工（有条件通过 → 修复）

| 问题 | 处理 |
|---|---|
| 失败后没有重试入口 | 错误块增加“重试”，沿用同一内容且不重复追加用户消息；文案改为“请求未完成” |
| `status_text` 缺少后端断言 | API 集成测试断言 `status_text == "待发货"` |
| 网络异常、澄清、Enter、禁用态缺测试 | 补 5 条用例；503 用例改基座豁免 |
| `conversation_id` 未回传，每轮新建会话 | 首轮保存并随后续请求回传，补续接用例 |
| 加载态未禁用输入、气泡配色不符规范 | busy 时禁用输入与发送；气泡改为 `--surface-2`、圆角与内边距按 ui-spec；数字用 `tabular-nums` |
| 中文输入法 Enter 误发送 | 判断 `isComposing` 后直接返回 |
| 空态建议按钮无行为 | 点击发送固定问句 |
| 消息区无 live region | 日志区 `role="log" aria-live`，加载态 `role="status"`，composer `aria-busy` |

说明：

- 订单卡片的状态文案来自后端 `status_text`，前端不维护第二份映射。
- 刷新后不恢复历史、不显示 trace_id，均为已确认决策；设计第 12 节已同步。
