## 4. 证据

### 4.1 评审返工（有条件通过 → 修复）

| 问题 | 处理 |
|---|---|
| 订单上下文只取最近一条取消任务 | 从会话消息中提取订单号，并与最新任务合并去重 |
| 文字“转人工”仍回复“后续版本开放” | `HUMAN_HANDOFF` 接入 `create_handoff`，返回 `transferred`；前端据此停回复 |
| 重复转接生成多张交接单 | 同会话已有交接单直接返回；迁移 0005 加 `(tenant,user,conversation)` 唯一约束；前端 busy 禁用 |
| 空会话转接后快捷按钮仍可发消息 | 保存 `handoff` 返回的 `conversation_id`；`submit`/快捷按钮/确认卡片在转接后禁用；`/message` 409 映射为“已转人工” |
| 转接后仍可确认取消 | 前端确认卡片随转接禁用；后端限制登记为遗留 |
| `pending_step` 缺 `COLLECTING`/`MANUAL_REVIEW` | 已补映射 |
