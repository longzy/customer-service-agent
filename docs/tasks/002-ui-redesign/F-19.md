## 1. 改变范围

- 用户可感知行为：坐席在队列里看到固定列宽、超时标记、筛选排序与键盘流，能领取会话。
- 涉及层：前端
- 本次改变：三栏布局；队列表格；筛选/排序/搜索；J/K/Enter/⌘K/Esc；409/404 提示与刷新；组件拆分（Nav/Header/Toolbar/Table/Body/KeyBar/Fallback）。
- 本次不改变：队列接口、领取接口、权限、服务端 FIFO。

## 2. 决策

| ID | 问题 | 决定 | 理由 |
|---|---|---|---|
| D-1 | 是否前端重排 | 默认按等待时长降序，与 FIFO 一致 | 设计稿“最久优先” |
| D-2 | 批量领取 | 禁用并标注需服务端支持 | 不放假功能 |
| D-3 | 窄屏领取 | <768 显示提示、不发起领取 | 只读降级 |
