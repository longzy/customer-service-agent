# 任务执行卡：F-01 客户登录、会话恢复与登出

- 关联 feature：F-01

- 绑定验收：AC-30
- 状态：待开工许可
- 变更级别：T3（客户认证/session）
- 设计引用：认证、cookie、session、恢复、错误码以 plan 3.3.2/3.3.3/3.4 为准，本卡不重复描述

## 1. 改变范围

- 本卡交付的用户可感知行为（只能一个）：客户用种子账号登录，刷新/重新登录恢复同一未关闭会话；登出或过期后 401；跨客户访问 404。
- 涉及层：迁移 / 后端 / 前端 / 测试

- 本次改变：
  - 新增 `service_customers`、`service_customer_sessions` 表与迁移（plan 3.2）。
  - 新增 `backend/identity` 客户密码校验/session 创建/轮换/撤销；`backend/api/customer_routes.py` 的登录/登出/当前会话。
  - 新增 `apps/chat` `/login` 与 `/chat` 最小页面 + session gate。
  - 种子脚本创建 `customer_a`/`customer_b`；密码从 `.env` 的 `DEMO_PASSWORD` 读取，不提交真实密码（ADR-0006）。
  - 新增 `tests/integration/test_customer_auth_AC_30.py`。
- 本次不改变：
  - 坐席登录、消息/AI、转人工、队列、审计/限速（F-02+）。
  - 旧 M1-P 路由/表/测试。
  - 不做客户注册/找回密码/OTP/MFA。

## 2. 任务级决策

### 2.1 需人类决策

无。演示账号命名按 plan 3.2（`customer_a`/`customer_b`）；密码按 ADR-0006 从 `.env` 的 `DEMO_PASSWORD` 读取，不提交真实密码。

### 2.2 声明的 seam

| ID | 内部接口 | 为什么测试直接驱动它 |
|---|---|---|
| S-1 | `POST /customer/sessions` | AC-30 登录/Set-Cookie/401/429 |
| S-2 | `GET /customer/session` | 恢复、`after_id`、401 |
| S-3 | `DELETE /customer/sessions` | 登出撤销、后续 401 |
| S-4 | `service_customer_sessions` | token 哈希、24h 过期、轮换 |
| S-5 | Cookie 属性 | `HttpOnly`/`SameSite=Lax`/`Secure(prod)`/`Max-Age` |

### 2.3 实现者自行决定

| ID | 问题 | 决定 | 理由 | 返工代价 |
|---|---|---|---|---|

### 2.4 判定表与失败矩阵

| AC | 主路径 | 非法输入 | 权限 | 下游故障 | 并发/重复 | 幂等 | 配置门禁 |
|---|---|---|---|---|---|---|---|
| AC-30 | 登录 200 + Set-Cookie；GET 恢复；刷新仍 200 | 错密码/空字段 → 401/422 | customer_b 读 customer_a → 404 | DB 不可用 → 5xx（全局错误封套） | 二次登录轮换 token，旧 token 401 | GET 幂等 | production `Secure`；24h 过期 |
