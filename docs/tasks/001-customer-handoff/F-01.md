## 1. 改变范围

- 本卡交付的用户可感知行为（只能一个）：客户用种子账号登录，刷新/重新登录恢复同一未关闭会话；登出或过期后 401；跨客户访问 404。
- 涉及层：迁移 / 后端 / 前端 / 测试

- 本次改变：
  - 新增 `service_customers`、`service_customer_sessions`、`service_conversations`、`service_rate_limit_buckets` 表与迁移 `0007_service_customer_auth`（plan 3.2；会话恢复与登录限速需要）。
  - 新增 `backend/identity/passwords.py`、`customer_sessions.py`：scrypt、session 创建/轮换/撤销、24h 过期、惰性空闲关闭、登录限速。
  - `backend/api/customer_routes.py`：`POST/GET/DELETE /customer/sessions`、`GET /customer/session`、`GET /customer/conversations/{id}`。
  - 新增 `apps/chat` `/login` 与 `/chat` 最小页面 + session gate。
  - 种子脚本 `scripts/seed_demo.py` 创建 `customer_a`/`customer_b`；密码从 `.env` 的 `DEMO_PASSWORD` 读取，不提交真实密码（ADR-0006）。
  - 新增 `tests/integration/test_customer_auth_AC_30.py`；更新 OpenAPI/DB schema 快照与 `verify.sh`（接入 `apps/chat`）。
- 本次不改变：
  - 坐席登录、消息/AI、转人工、队列、审计/限速（F-02+）。
  - 旧 M1-P 路由/表/测试。
  - 不做客户注册/找回密码/OTP/MFA。

## 2. 任务级决策

### 2.1 需人类决策

无。演示账号命名按 plan 3.2（`customer_a`/`customer_b`）；密码按 ADR-0006 从 `.env` 的 `DEMO_PASSWORD` 读取，不提交真实密码。

### 2.2 声明的 seam

| ID | 内部接口 | 为什么测试直接驱动它 |
|---|---|---|
| S-1 | `POST /customer/sessions` | AC-30 登录/Set-Cookie/401/429 |
| S-2 | `GET /customer/session` | 恢复、`after_id`、401 |
| S-3 | `DELETE /customer/sessions` | 登出撤销、后续 401 |
| S-4 | `service_customer_sessions` | token 哈希、24h 过期、轮换 |
| S-5 | Cookie 属性 | `HttpOnly`/`SameSite=Lax`/`Secure(prod)`/`Max-Age` |

### 2.3 实现者自行决定

| ID | 问题 | 决定 | 理由 | 返工代价 |
|---|---|---|---|---|
| D-1 | 种子脚本位置 | `scripts/seed_demo.py` | 与现有 `scripts/` 一致 | 小 |
| D-2 | 密码来源 | `.env` 的 `DEMO_PASSWORD`；缺失时脚本失败 | ADR-0006：不提交真实密码 | 小 |
| D-3 | token 生成 | `secrets.token_urlsafe(32)`，存 SHA-256 | 256-bit，不存明文 | 小 |
| D-4 | 测试文件 | `tests/integration/test_customer_auth_AC_30.py` | 按 AC 命名，trace 可追溯 | 小 |
| D-5 | 跨客户 404 的资源入口 | 新增只读 `GET /customer/conversations/{conversation_id}` | AC-30 的“会话 URL”与 F-14 需要按 id 做所有权校验；plan 3.3.3 客户 API 表已回写该接口（2026-11-17 用户确认） | 小（后续 feature 复用；若评审要求改路径只动路由） |
| D-6 | 客户登录的租户解析 | 服务端配置 `M1_TENANT_ID`（默认 `tenant-a`） | M1 单租户部署；请求体不得携带租户（INV-02） | 小 |
| D-7 | 限速窗口对齐 | 按整数秒对齐固定窗口，PG upsert 原子计数 | 避免浮点误差拆出多个桶导致限速失效 | 小 |

### 2.4 判定表与失败矩阵

| AC | 主路径 | 非法输入 | 权限 | 下游故障 | 并发/重复 | 幂等 | 配置门禁 |
|---|---|---|---|---|---|---|---|
| AC-30 | 登录 200 + Set-Cookie；GET 恢复；刷新仍 200 | 错密码/空字段 → 401/422 | customer_b 读 customer_a → 404 | DB 不可用 → 5xx（全局错误封套） | 二次登录轮换 token，旧 token 401 | GET 幂等 | production `Secure`；24h 过期 |
