## 1. 改变范围

- 本卡交付的用户可感知行为（只能一个）：坐席领取会话后可以接管；客户在领取后看到“正在接入人工”，接管后看到“人工已接入”；领取者能在会话页看到客户账号、消息、AI 轨迹、交接单与待办。
- 涉及层：后端 / 前端 / 契约（OpenAPI 前端类型）

- 本次改变：
  - `backend/conversations/workspace_conversations.py`：
    - `claim_handoff` 增加 `trace_id`，领取同事务写系统消息 `正在接入人工`（显式承接 plan 3.4 与 F-07 评审条件）。
    - 新增 `take_over_conversation`：会话 `CLAIMED → HUMAN_ACTIVE`、交接单 `CLAIMED → ACTIVE`，条件更新 + 系统消息 `人工已接入`。
    - 新增 `get_assigned_conversation_detail`：按租户与 `assigned_employee_id` 读取客户、最近一张交接单、消息快照、AI 轨迹与待办；投影函数对 JSON 快照做类型收敛。
  - `backend/conversations/schemas.py`：`WorkspaceConversationResponse` 扩展为 `customer` + `handoff`；新增 `WorkspaceTakeoverResponse`、`WorkspaceHandoffDetail`、`WorkspaceContextMessage`、`WorkspaceAiTraceEvent`、`WorkspaceCustomerPublic`。
  - `backend/conversations/workspace_http.py`：`POST /workspace/conversations/{id}/takeover`；`GET /workspace/conversations/{id}` 返回完整上下文；领取路由传入 `X-Request-ID` 作为系统消息 `trace_id`。
  - `apps/workspace/features/conversation/api/conversation.ts`、`types.ts`：新增 `takeOverConversation` 与生成类型。
  - `apps/workspace/features/conversation/components/ConversationDetailPanel.tsx`、`ConversationGate.tsx`：会话页展示客户/交接单/消息/AI 轨迹/待办，`CLAIMED` 时提供“接管会话”，成功后状态更新；404/409 分别提示。
  - `apps/workspace/lib/format.ts`：时间格式化入口（FE-DATA-04）。
  - `apps/chat/features/chat/components/ChatShell.tsx`：领取后不再把“排队中，请稍候”与“正在接入人工”同时展示。
  - 测试：`tests/integration/test_workspace_takeover_AC_36.py`（9 条集成用例）；`apps/workspace/tests/ConversationGate.test.tsx`（上下文、接管成功、404）；`apps/chat/tests/ChatShell.test.tsx`（客户看到两条系统文案）；`tests/integration/test_workspace_auth_AC_34.py` 的会话读取断言按扩展后的契约更新（`id`/`status`/`customer`/`handoff: null`），AC-34 的权限语义不变。
  - 测试夹具：`tests/integration/workspace_support.py` 的 `seed_queued_handoff` 增加 `assigned_employee_id`、`summary`、`context`，供关闭/跨租户/上下文用例播种。
  - 契约：重新导出 `packages/contracts/openapi.json`、`tests/fixtures/openapi-r0-2.json` 与两个 `api-types.ts`；`domain.json`/`tools/openapi.json` 无错误码变化。
- 本次不改变：
