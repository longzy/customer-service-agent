# 术语表

面向人类与 Agent 的项目术语；首次出现在总结里时，用一句解释带过。

| 术语 | 含义 |
|---|---|
| AC | Acceptance Criteria，验收标准；格式 `AC-01`，测试名以 `_AC_01` 结尾 |
| 阻断项 | 必须修完才能评审通过/合并的问题；不修就不能签字 |
| 非阻断遗留 | 已登记、可接受、不影响本次验收的问题；后续任务或触发条件出现时处理 |
| S1.5 | 规格可判定性评审：未参与写作的上下文回答五问，输出“可判定/退回” |
| T0–T3 | 变更分级：T0 微改、T1 常规、T2 结构性、T3 高风险；决定卡、评审人数与门禁 |
| G0–G4 | 门禁阶梯：本地检查、CI、验证、发布等；服务端 CI 是唯一硬门禁 |
| Seam | 测试或调用直接驱动的内部接口；卡里必须声明，评审检查是否被悄悄驱动 |
| 场景评测 | 固定夹具下的端到端/多轮评测；T-13 用 pytest JUnit 聚合 + 多轮场景 |
| Trace | 一次请求的完整链路标识；关联消息、工具、状态转换与审计 |

维护：术语只在首次出现时解释；不要在每个任务卡里重复定义。
