# UI 规范与组件规范

- 状态：已批准
- 批准：2026-11-14（本次会话由用户确认）
- 日期：2026-11-14
- 适用：M1 及后续里程碑的前端实现
- 关联：`docs/specs/M1-order-cancel/ui.md`（页面与交互规则）、`docs/specs/M1-order-cancel/ui-mockup.html`（结构参考稿）

## 1. 范围与原则

本文定义设计令牌和组件契约，供实现与评审共同引用。页面结构与交互流程仍以 `ui.md` 为准；两者冲突时，交互规则以 `ui.md` 为准，视觉取值以本文为准。

三条原则：

- 中性优先：界面 80% 以上由中性色构成，强调色只标记可交互与当前状态。
- 形状克制：圆角与描边统一，层次优先靠留白、字号与明暗方向，不靠加深边框。
- 文字承载语义：颜色只做辅助，任何状态都必须有文字说明。

## 2. 设计令牌

### 2.1 颜色

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--bg` | `#FAFAFA` | 页面底、输入框默认底 |
| `--surface` | `#FFFFFF` | 卡片、对话区、聚焦态输入框 |
| `--surface-2` | `#F4F4F5` | 用户气泡、禁用底、图标底板 |
| `--border` | `#E8E8EC` | 分区线、卡片描边 |
| `--border-strong` | `#D6D6DD` | 次要按钮描边、发送按钮禁用 |
| `--input-border` | `#E4E4E7` | 输入框默认描边 |
| `--text` | `#18181B` | 正文 |
| `--text-2` | `#52525B` | 次要文字、说明 |
| `--text-3` | `#71717A` | 占位、时间、元信息；对白底 4.83:1，可承载次要文字 |
| `--accent` | `#2563EB` | 主按钮、焦点、链接、当前步骤 |
| `--accent-soft` | `#EFF6FF` | 强调色浅底 |
| `--success` | `#059669` | 成功状态圆点与文字 |
| `--warning` | `#B45309` | 需注意状态 |
| `--danger` | `#DC2626` | 危险操作按钮、不可撤销提示 |
| `--danger-soft` | `#FEF2F2` | 危险提示底 |

规则：

- 强调色占屏面积不超过 5%。
- 语义色只用语义，不拿红色做装饰，不拿绿色做按钮底色。

### 2.2 字体与字号

系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", Arial, sans-serif`。不引入远程字体。

| 令牌 | 字号 / 行高 | 用途 |
|---|---|---|
| `text-xs` | 11 / 1.5 | 键位提示、字数、时间 |
| `text-sm` | 12.5 / 1.6 | 辅助说明、卡片次要行 |
| `text-base` | 13.5 / 1.7 | 正文、消息、输入 |
| `text-md` | 14 / 1.7 | 强调正文（状态行） |
| `text-lg` | 15 / 1.5 | 区块标题 |
| `text-xl` | 22 / 1.3 | 页面标题 |

- 字重只用 400 / 500 / 600；不使用 700 以上，避免压迫感。
- 订单号、金额、计数使用 `font-variant-numeric: tabular-nums`。
- 标题字距 `-0.01em` 至 `-0.02em`。

### 2.3 间距与布局

间距基数 4px，允许值：`2 / 4 / 6 / 8 / 12 / 16 / 24 / 32`。禁止使用 5、7、9、10、14 这类非标值；需要微调时改行高或内边距。

| 区域 | 取值 |
|---|---|
| 页面外边距 | 32 |
| 左侧窄栏宽度 | 72 |
| 会话标题栏高度 | 56，水平内边距 26 |
| 消息区最大宽度 | 820，水平内边距 26 |
| 消息文本最大宽度 | 560 |
| 确认卡片最大宽度 | 470 |
| 消息间距 | 18 |
| 输入区内边距 | 上 12 / 右 12 / 下 10 / 左 14 |

### 2.4 圆角与阴影

| 令牌 | 取值 | 用途 |
|---|---|---|
| `radius-sm` | 4 | 键位提示、气泡内角 |
| `radius-md` | 9 | 常规按钮 |
| `radius-lg` | 10 | 图标按钮、图标底板 |
| `radius-xl` | 14 | 卡片、输入框、气泡外角 |
| `radius-pill` | 999 | 状态胶囊 |

阴影只用于浮起层：

- 卡片：`0 1px 2px rgba(24,24,27,.05), 0 16px 32px -24px rgba(24,24,27,.3)`
- 焦点：`0 0 0 3px rgba(37,99,235,.12)`
- 页面外框：`0 1px 2px rgba(24,24,27,.05), 0 32px 64px -40px rgba(24,24,27,.32)`

平面元素不加阴影；需要区分时用 1px 描边。

### 2.5 图标

- 内联 SVG，尺寸 16 或 20，线宽 1.6，端点圆角，颜色继承 `currentColor`。
- 不引入图标库、图标字体或远程资源。
- 图标必须配文字或 `title`，不单独承载语义。

## 3. 组件契约

每个组件按「结构 → 尺寸 → 状态 → 规则」描述。状态矩阵是验收依据。

### 3.1 左侧窄栏 `rail`

- 结构：品牌方块 → 分隔线 → 当前页图标（高亮）→ 弹性空白 → 帮助 → 转人工。
- 尺寸：宽 72，图标按钮 40×40，圆角 10，品牌方块 36×36。
- 状态：默认（描边 + `--text-2`）、当前（`--accent` 底 + 白图标）。
- 规则：只放全局入口，不放会话列表；高亮项同一时刻只能有一个。

### 3.2 会话标题栏 `convhead`

- 结构：标题 → 在线胶囊 → 弹性空白 → 会话元信息。
- 尺寸：高 56，内边距 26，标题 14/600。
- 规则：元信息使用 `--text-3`；在线胶囊必须带圆点，不能只用颜色区分。

### 3.3 按钮 `button`

| 变体 | 底色 | 文字 | 描边 | 用途 |
|---|---|---|---|---|
| `primary` | `--accent` | 白 | 无 | 页面主操作、发送 |
| `danger` | `--danger` | 白 | 无 | 不可撤销的确认 |
| `secondary` | `--surface` | `--text-2` | `--border-strong` | 取消、次要操作 |
| `icon` | `--accent` / 透明 | 白 / `--text-2` | 视变体 | 发送、窄栏入口 |

- 尺寸：常规高 38，内边距 10×14，圆角 9；图标按钮 34×34，圆角 10。
- 状态：默认、悬停（底色降一档明度）、焦点（`0 0 0 3px` 焦点环）、禁用（底色 `--border-strong`，透明度 0.4，取消悬停）。
- 规则：一个操作区最多一个 `primary` 或 `danger`；禁用态必须同时改变无障碍属性，不能只改颜色。

### 3.4 消息 `message`

- 系统消息：无气泡，正文色 `--text`，最大宽 560。
- 用户消息：`--surface-2` 底，内边距 10×14，圆角 `14 14 4 14`，右对齐。
- 规则：气泡与对话区底色必须可分辨；两者都接近白色时，改用描边或加深气泡。

### 3.5 状态行 `status`

- 结构：6px 圆点 + 文字，圆点垂直居中于首行。
- 颜色：圆点取对应语义色，文字用 `--text-2`，关键字加粗并使用 `--text`。
- 规则：不使用色条、色块或彩色文字压浅底；状态必须同时有文字说明。

### 3.6 确认卡片 `confirm`

- 结构：头部（图标 + 标题 + 不可撤销标记）→ 商品行（缩略图、名称、订单号与状态、金额）→ 规则列表 → 影响提示 → 操作区。
- 尺寸：最大宽 470，内边距 16，圆角 14，头部底色 `--bg`。
- 状态：待确认（按钮可用）、提交中（按钮禁用、显示状态行）、终态（卡片收起）。
- 规则：四项信息缺一不可（订单号、商品、当前状态、影响）；危险按钮使用 `danger` 变体；卡片内不出现第二个危险操作。

### 3.7 建议入口 `suggestion`

- 结构：图标底板 34×34 + 标题 + 副标题。
- 尺寸：两列网格，间距 10，内边距 13×14，圆角 12。
- 规则：只作引导，不代替输入；点击后等价于用户发送该意图。

### 3.8 输入区 `composer`

- 结构：上行文本区；下行左侧键位提示、右侧「字数 + 发送」分组。
- 尺寸：内边距 12 / 12 / 10 / 14，圆角 14，发送按钮 34×34。
- 状态：

| 状态 | 底色 | 描边 | 其他 |
|---|---|---|---|
| 默认 | `--bg` | `--input-border` | 占位文字 `--text-3` |
| 聚焦 | `--surface` | `--accent` | 3px 焦点环 |
| 已输入 | `--surface` | `--input-border` | 文字转 `--text` |
| 禁用 | `--surface-2` | `--border` | 发送按钮转灰，不可编辑 |

- 规则：发送按钮必须由独立分组靠右，不能依赖提示文字或字数是否存在；字数上限默认 500。

### 3.9 胶囊 `chip` 与标记 `tag`

- 结构：圆点（可选）+ 文字。
- 尺寸：字号 11，内边距 3×9，圆角 999，描边 `--border`。
- 变体：`live`（在线，成功色）、`tag`（不可撤销，危险色浅底）。
- 规则：同类胶囊在一屏内不超过两种语义。

### 3.10 键位提示 `kbd`

- 字号 10.5，内边距 0×4，描边 `--border` 且下边框 2px，圆角 4。
- 规则：只用于输入区提示，不放进按钮或正文。

## 4. 状态矩阵（验收用）

| 组件 | 默认 | 悬停 | 聚焦 | 禁用 | 错误 |
|---|---|---|---|---|---|
| `button` | 必需 | 必需 | 必需 | 必需 | — |
| `composer` | 必需 | — | 必需 | 必需 | 超长时提示 |
| `message` | 必需 | — | — | — | — |
| `status` | 必需 | — | — | — | — |
| `confirm` | 必需 | — | 必需 | 提交中 | — |
| `suggestion` | 必需 | 必需 | 必需 | — | — |

## 5. 可访问性底线

- 所有交互可用键盘完成，焦点可见，焦点环不得被 `outline: none` 移除。
- 状态用文字表达，颜色仅作辅助；色盲用户应能仅凭文字完成判断。
- 图标按钮必须有无障碍名称。

实测对比度（按 WCAG 2.1 相对亮度公式计算）：

| 组合 | 对比度 | AA 正文 4.5 | AA 非文本 3.0 |
|---|---|---|---|
| 正文 `#18181B` / 白 | 17.72 | 通过 | 通过 |
| 次要文字 `#52525B` / 白 | 7.73 | 通过 | 通过 |
| 辅助文字 `#71717A` / 白 | 4.83 | 通过 | 通过 |
| 强调 `#2563EB` / 白 | 5.17 | 通过 | 通过 |
| 白字 / 强调底 | 5.17 | 通过 | 通过 |
| 白字 / 危险 `#DC2626` | 4.83 | 通过 | 通过 |
| 警告 `#B45309` / 白 | 5.02 | 通过 | 通过 |
| 成功 `#059669` / 白 | 3.77 | 不通过 | 通过 |
| 描边 `#D6D6DD` / 白 | 1.45 | 不通过 | 不通过 |
| 气泡 `#F4F4F5` / 白 | 1.10 | — | — |

由此产生三条硬约束：

- `--success` 只用于圆点和图标，不用于正文。需要成功色文字时改用 `#047857`（5.48:1）。
- 输入框与按钮边界对比度低于 3:1，属于已知取舍：靠聚焦态、标签与占位文字补偿。若必须严格满足 WCAG 1.4.11，把 `--input-border` 改为 `#8E8E98`（3.24:1），代价是界面明显变重。
- 气泡 `#F4F4F5` 与白底只差 1.10，颜色本身不足以区分角色，所以用户消息必须同时具备右对齐与圆角形态。

## 6. 明确不做

- 渐变、玻璃拟态、发光边框、粒子或装饰插画。
- 图标字体、远程字体与远程图标资源。
- 表情符号、感叹号堆砌、拟人化语气。
- 多处并存的强调色，或把语义色用于装饰。
