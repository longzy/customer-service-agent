## 设计基调

同一品牌、两种语调：

- 品牌：回声 ECHO；深松绿 `#13211C` 承载锚点，品牌绿 `#0F5C4C` 承担主操作，暖沙 `#F2EBDD` 提供情绪面。
- 客户侧：衬线标题、大留白、单一主 CTA；登录与对话共用左侧品牌区。
- 坐席侧：无衬线、固定列宽、信息密度、键盘流；登录页声明审计与环境，不欢迎“品牌化”。
