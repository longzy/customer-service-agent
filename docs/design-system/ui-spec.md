## 1. 范围与原则

本文定义设计令牌和组件契约，供实现与评审共同引用。页面结构与交互流程以当前 spec 的 `plan.md` 为准；两者冲突时，交互规则以 `plan.md` 为准，视觉取值以本文为准。

三条原则：

- 中性优先：界面 80% 以上由中性色构成，强调色只标记可交互与当前状态。
- 形状克制：圆角与描边统一，层次优先靠留白、字号与明暗方向，不靠加深边框。
- 文字承载语义：颜色只做辅助，任何状态都必须有文字说明。

## 2. 设计令牌

### 2.1 颜色

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--brand-deep` | `#13211C` | 品牌锚点：客户侧品牌栏、坐席侧侧栏 |
| `--accent` | `#0F5C4C` | 主按钮、焦点、链接、当前状态 |
| `--accent-soft` | `#EAF2EE` | 强调浅底、选中行、在线胶囊 |
| `--sand` | `#F2EBDD` | 客户侧欢迎卡、等待卡 |
| `--bg` | `#F6F5F1` | 页面画布 |
| `--paper` | `#FFFCF6` | 客户侧纸面、对话区 |
| `--surface` | `#FFFFFF` | 卡片、聚焦态输入框 |
| `--surface-2` | `#F4F4F2` | 坐席侧用户气泡、禁用底 |
| `--border` | `#E6E2D8` | 分区线、卡片描边 |
| `--border-strong` | `#D6D2C6` | 次要按钮描边 |
| `--input-border` | `#DCD7CA` | 输入框默认描边 |
| `--text` | `#1B1B17` | 正文 |
| `--text-2` | `#57554E` | 次要文字、说明 |
| `--text-3` | `#726F65` | 占位、时间、元信息；对纸面 4.91:1 |
| `--success` | `#1F8A6C` | 成功状态圆点与图标 |
| `--warning` | `#94550A` | 需注意状态、等待中 |
| `--warning-soft` | `#F8EFDF` | 等待提示底 |
| `--danger` | `#B4441C` | 危险按钮、超时标记 |
| `--danger-soft` | `#FBEEE8` | 危险提示底 |

规则：

- 强调色占屏面积不超过 5%。
- 语义色只用语义，不拿红色做装饰，不拿绿色做按钮底色。

### 2.2 字体与字号

- `--font-sans`：系统无衬线，用于全部正文与坐席侧标题。
- `--font-serif`：`"Songti SC", "Noto Serif SC", "Source Han Serif SC", Georgia, serif`，只用于客户侧标题与欢迎语；不引入远程字体。

字号 token 与下表同名（`--text-xs` 至 `--text-xl`）。

| 令牌 | 字号 / 行高 | 用途 |
|---|---|---|
| `text-xs` | 11 / 1.5 | 键位提示、字数、时间 |
| `text-sm` | 12.5 / 1.6 | 辅助说明、卡片次要行 |
| `text-base` | 13.5 / 1.7 | 正文、消息、输入 |
| `text-md` | 14 / 1.7 | 强调正文（状态行） |
| `text-lg` | 15 / 1.5 | 区块标题 |
| `text-xl` | 22 / 1.3 | 页面标题 |

- 字重只用 400 / 500 / 600；不使用 700 以上，避免压迫感。
- 订单号、金额、计数使用 `font-variant-numeric: tabular-nums`。
- 标题字距 `-0.01em` 至 `-0.02em`。

### 2.3 间距与布局

间距基数 4px，令牌 `--space-1`..`--space-8` 对应 `2 / 4 / 6 / 8 / 12 / 16 / 24 / 32`。禁止 5、7、9、10、14 等非标值；需要微调时改行高或内边距。

| 区域 | 取值（示例，实现取最近令牌） |
|---|---|
| 页面外边距 | 32 |
| 左侧窄栏宽度 | 72 |
| 会话标题栏高度 | 56，水平内边距 26 |
| 消息区最大宽度 | 820，水平内边距 26 |
| 消息文本最大宽度 | 560 |
| 确认卡片最大宽度 | 470 |
| 消息间距 | 18 |
| 输入区内边距 | 上 12 / 右 12 / 下 10 / 左 14 |

### 2.4 圆角与阴影

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--radius-sm` | 4 | 键位提示、气泡内角 |
| `--radius-md` | 9 | 常规按钮 |
| `--radius-lg` | 10 | 图标按钮、图标底板 |
| `--radius-xl` | 14 | 卡片、输入框、气泡外角 |
| `--radius-pill` | 999 | 状态胶囊 |

阴影只用于浮起层：

- 卡片：`--shadow-card`
- 浮起层：`--shadow-float`
- 焦点：`--focus-ring`

平面元素不加阴影；需要区分时用 1px 描边。

### 2.5 图标

- 内联 SVG，尺寸 16 或 20，线宽 1.6，端点圆角，颜色继承 `currentColor`。
- 不引入图标库、图标字体或远程资源。
- 图标必须配文字或 `title`，不单独承载语义。

### 2.6 样式承载

- 组件样式统一用 CSS Modules：`Component.module.css` 与组件同目录，类名 camelCase，通过 `styles.xxx` 引用。
- 全局 CSS 只保留两类：`app/globals.css`（reset、html/body 排版、字体栈）与 `tokens.css`（令牌）。禁止新增全局选择器。
- 现有全局类名（`.app`、`.chat-card`、`.queue-item` 等）在 S2/S3 改版时随组件迁入 Modules；迁移完成前允许保留，但不得新增。
- 禁止 `!important`、id 选择器、超过 2 层的标签嵌套；动态内联样式只允许数值型令牌（如进度宽度），并注释原因。
- Modules 内同样只引用令牌，不写颜色字面量。

### 2.7 动效

只允许三类，超出即视为违规：

| 类型 | 参数 | 用在哪里 |
|---|---|---|
| 入场 | 240ms `cubic-bezier(0.2, 0, 0, 1)`，`opacity 0→1` + `translateY(6px→0)` | 每页最多一处（首屏或消息区） |
| 状态反馈 | 120ms `ease-out` | hover、active、focus、按钮加载态 |
| 循环 | 等待脉冲 1600ms `ease-in-out infinite`；加载 spinner 900ms `linear infinite` | 等待卡、加载态 |

- 禁止：自动轮播、视差、装饰性循环动画、超过 300ms 的交互反馈、用 `width/height/top/left` 做布局动画；抽屉与详情只允许 `transform` 200ms。
- `prefers-reduced-motion: reduce`：移除入场与脉冲，状态变化即时生效；spinner 改为静态加载文字。
- 动画期间控件仍可聚焦、可点击；不得用动画隐藏真实状态。

### 2.8 响应式

| 断点 | 客户侧 | 坐席侧 |
|---|---|---|
| ≥1280 | 设计基准；对话区最大宽 820 | 侧栏 224 + 队列 + 详情 352 |
| 1024–1279 | 品牌栏 300，对话区自适应 | 侧栏 200、详情 320，隐藏“订单”列 |
| 768–1023 | 品牌栏折叠为顶部 56 头 | 详情改为点击行打开的覆盖层，隐藏“原因”“订单” |
| <768 | 单列全屏；输入区固定底部；快捷入口两列 | 只读列表 + “请使用桌面端领取”，不提供领取 |

- 表格优先横向滚动，不压缩列宽；禁止把关键列藏到需要横向滚动才能发现的位置。
- 移动端只重排现有组件，不新增组件；必须新增时先补本节与组件契约。
- 断点用 `max-width` 与 `min-width` 成对书写，避免断档；不引入 CSS 框架的断点变量。

### 2.9 视觉验收基线

- 基线引用 [proposals/](proposals/README.md) 的五张页面稿与组件参考页；[baseline/](baseline/README.md) 只记录冻结哈希与比对流程，不复制图片。
- 实现完成后按同一视口截图并排比对；差异分三类：允许（字体抗锯齿）、需修（间距/颜色/字号）、阻断（布局/信息缺失/状态缺失）。
- 基线变更必须先改本文或设计稿并说明原因，再重截图并更新 baseline 的哈希记录，最后改代码；禁止只改代码或只换图。
- 截图命令与比对流程见 baseline/README。

## 3. 组件契约

每个组件按「结构 → 尺寸 → 状态 → 规则」描述。状态矩阵是验收依据；尺寸取 [tokens.css](tokens.css) 令牌。

### 3.1 品牌栏 `brand`

- 结构：logo（标记 + 中英文名）→ 衬线标题 → 说明 → 在线状态卡 → 脚注。
- 尺寸：客户侧登录 400、聊天 340；坐席侧登录 520；内边距 34–40；页面内圆角 28。
- 状态：在线（成功圆点 + 文案）、非服务时间（灰点 + 留言说明）。
- 规则：只承载品牌与状态，不放导航与操作；衬线标题只用于客户侧，坐席侧用 `--font-sans`。

### 3.2 导航与顶栏 `nav` / `topbar`

- 结构（坐席侧）：品牌 → 工作区导航 → 管理 → 坐席卡；顶栏为面包屑 → 搜索 → 通知 → 在线胶囊 → 头像。
- 尺寸：侧栏 224，导航项 38，图标 16；顶栏 60，搜索 300×32；客户侧窄栏 72 为历史变体。
- 状态：默认、当前（`--accent-soft` 文字 + 左侧 2px 指示）、未开放（`--text-3` + “即将开放”）。
- 规则：当前项同一时刻只能有一个；未开放项不得可点击；搜索必须显示 `⌘K`。

### 3.3 按钮 `button`

| 变体 | 底色 | 文字 | 描边 | 用途 |
|---|---|---|---|---|
| `primary` | `--accent` | 白 | 无 | 页面主操作、发送、领取 |
| `secondary` | `--surface` | `--text-2` | `--border` | 取消、次要操作 |
| `ghost` | 透明 | `--text-2` | 无 | 刷新、退出、关闭 |
| `danger` | `--danger` | 白 | 无 | 不可撤销操作 |

- 尺寸：常规高 32–38，登录与主 CTA 高 42–44；内边距 10×14；圆角 `--radius-md` 或 `--radius-lg`。
- 状态：默认、悬停、焦点（`--focus-ring`）、禁用（灰底 + `aria-disabled`）。
- 规则：一个操作区最多一个 `primary`；禁用态必须同时改变无障碍属性，不能只改颜色。

### 3.4 输入框 `field`

- 结构：label → 输入框 → 可选提示；密码框含可见切换。
- 尺寸：高 42–44，内边距 0×12，圆角 9–10；label 11.5/500。
- 状态：默认、聚焦（`--accent` 描边 + `--focus-ring`）、禁用、错误（`--danger` 描边 + `role="alert"`）。
- 规则：错误文案必须与字段关联（`aria-describedby`）；密码切换必须有 `aria-label`。

### 3.5 消息 `message`

- 结构：头像（可选）→ 气泡 → 时间戳；系统消息无气泡。
- 尺寸：气泡最大宽 560，内边距 10–11×14，圆角 `14 14 4 14`。
- 客户侧用户气泡：`--brand-deep` 底、`--paper` 字；坐席侧用户气泡：`--surface-2` 底、`--text` 字。
- 状态：发送中、已发送、失败（可重试）、转人工后只读。
- 规则：客户与坐席气泡手感必须不同；时间戳用 `--text-3` + tabular-nums；消息流 `aria-live="polite"`。

### 3.6 等待卡 `handoff`

- 结构：状态圆点 → 标题 → 说明（转人工状态与可继续补充；等待秒数与位次待客户接口扩展，不在前端估算）。
- 尺寸：最大宽 640，内边距 13×16，圆角 `--radius-xl`，底色 `--warning-soft`，描边 `#ECD9BB`。
- 状态：排队中（脉冲圆点）、已接通（转 `--success`）、超时（转 `--danger` 并给文案）。
- 规则：等待数字来自服务端；不得用动画速度暗示进度。

### 3.7 队列表格 `queue`

- 结构：表头 → 行（客户、等待、原因、末条消息、订单、状态、操作）→ 底栏。
- 尺寸：表头 38，行 56；列宽 40 / 168 / 70 / 122 / 自适应 / 50 / 78 / 76；客户列含 28px 头像。
- 状态：默认、选中（`#F0F4F1` + 左 3px `--accent`）、已超时（等待与状态转 `--danger`）、加载、空、错误。
- 规则：超时阈值 5 分钟且必须同时有文字；保留服务端 FIFO 顺序，前端不重排；滚动时表头固定。

### 3.8 工具栏 `toolbar`

- 结构：状态 tab（含计数）→ 右侧搜索 / 原因 / 排序。
- 尺寸：tab 高 40，选中下划线 2px；控件高 30，圆角 8。
- 规则：筛选变化回到第一页并保留可见条件；空结果与无权限必须区分。

### 3.9 详情面板 `detail`

- 结构：客户块 → 三指标（等待 / 原因 / 订单）→ 脱敏末条 → 脱敏提示 → 领取规则 → 主次操作；完整上下文在领取后的会话页展示。
- 尺寸：宽 352，内边距 22；指标网格 3 列；主按钮高 38。
- 状态：未领取、领取中、已领取（按钮转“进入会话”）、无权限。
- 规则：只展示本租户数据；脱敏提示与内容同时出现；领取按钮只在可领取时可用。

### 3.10 胶囊与状态 `chip` / `status`

- 尺寸：chip 高 24、字号 11、内边距 0×10、圆角 `--radius-pill`；status 圆点 7。
- 变体：`live`（成功）、`warning`（等待）、`danger`（超时）、`neutral`（默认）。
- 规则：状态必须文字 + 圆点，颜色只作辅助；一屏同类胶囊不超过两种语义。

### 3.11 空 / 错 / 无权限 `empty` / `error` / `denied`

- 结构：38px 圆形图标 → 标题 → 说明 → 操作。
- 状态：加载（骨架保留列宽）、空（给出下一步）、错误（保留错误码与重试）、无权限（403 与空队列区分）。
- 规则：错误态不得伪装成空态；重试按钮必须可用；空态不写“暂无数据”。

### 3.12 键位提示 `kbd`

- 尺寸：字号 10，内边距 1×5，边框 1px + 下边框 2px，圆角 4。
- 用法：输入区提示、键盘条、搜索框快捷键；只描述真实存在的快捷键。
- 规则：键盘流必须可发现（常驻提示或 `?` 面板），焦点始终可见。

### 3.13 登录页

- 两套语境：客户侧（品牌区 400 + 表单卡 400）与坐席侧（品牌区 520 + 表单卡 400），共享输入框、按钮与错误提示。
- 客户侧标题用 `--font-serif`；页脚声明服务时间与隐私；账号由客服开通，不提供自助注册入口。
- 坐席侧页脚声明“内部系统 · 仅限员工使用”与审计；显示环境标识（开发/生产）。
- 字段：账号（客户）/ 工号或邮箱（坐席）、密码；密码可见切换必须有无障碍名称。
- 限速明示：客户侧“连续 5 次失败将锁定 15 分钟”；坐席侧“保持登录 8 小时”与审计说明。
- “开发期测试账号”只在开发环境展示；错误提示用 `role="alert"`。

### 3.14 归档组件

`confirm`（订单确认卡）随 `001-order-cancel` 规格删除；`suggestion` 并入客户侧欢迎卡的快捷入口；客户侧 72px `rail` 由品牌栏取代。三者不再实现。

## 5. 可访问性底线

- 所有交互可用键盘完成，焦点可见，焦点环不得被 `outline: none` 移除。
- 状态用文字表达，颜色仅作辅助；色盲用户应能仅凭文字完成判断。
- 图标按钮必须有无障碍名称。

实测对比度（按 WCAG 2.1 相对亮度公式计算）：

| 组合 | 对比度 | AA 正文 4.5 | AA 非文本 3.0 |
|---|---|---|---|
| 正文 `#1B1B17` / 纸面 `#FFFCF6` | 16.87 | 通过 | 通过 |
| 次要文字 `#57554E` / 纸面 | 7.29 | 通过 | 通过 |
| 辅助文字 `#726F65` / 纸面 | 4.91 | 通过 | 通过 |
| 品牌 `#0F5C4C` / 白 | 7.91 | 通过 | 通过 |
| 白字 / 品牌底 | 7.91 | 通过 | 通过 |
| 白字 / 危险 `#B4441C` | 5.55 | 通过 | 通过 |
| 警告 `#94550A` / 白 | 5.89 | 通过 | 通过 |
| 成功 `#1F8A6C` / 白 | 4.28 | 不通过 | 通过 |
| 描边 `#D6D2C6` / 白 | 1.51 | 不通过 | 不通过 |
| 气泡 `#F4F4F2` / 白 | 1.10 | — | — |

由此产生三条硬约束：

- `--success` 只用于圆点和图标，不用于正文。需要成功色文字时改用 `--accent`（7.91:1）。
- 输入框与按钮边界对比度低于 3:1，属于已知取舍：靠聚焦态、标签与占位文字补偿。若必须严格满足 WCAG 1.4.11，把 `--input-border` 改为 `#8C887B`（3.55:1），代价是界面明显变重。
- 气泡 `#F4F4F2` 与白底只差 1.10，颜色本身不足以区分角色，所以消息必须同时具备对齐方向与圆角形态。

## 6. 明确不做

- 渐变、玻璃拟态、发光边框、粒子或装饰插画。
- 图标字体、远程字体与远程图标资源。
- 表情符号、感叹号堆砌、拟人化语气。
- 多处并存的强调色，或把语义色用于装饰。
