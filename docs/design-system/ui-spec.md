## 1. 范围与原则

本文定义设计令牌和组件契约，供实现与评审共同引用。页面结构与交互流程以当前 spec 的 `plan.md` 为准；两者冲突时，交互规则以 `plan.md` 为准，视觉取值以本文为准。

三条原则：

- 中性优先：界面 80% 以上由中性色构成，强调色只标记可交互与当前状态。
- 形状克制：圆角与描边统一，层次优先靠留白、字号与明暗方向，不靠加深边框。
- 文字承载语义：颜色只做辅助，任何状态都必须有文字说明。

## 2. 设计令牌

### 2.1 颜色

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--brand-deep` | `#111827` | 品牌锚点：logo、极少数深色块 |
| `--brand-tint` | `#F3F5F7` | 登录页品牌区浅底 |
| `--accent` | `#111827` | 主按钮、焦点、当前状态 |
| `--accent-soft` | `#F3F4F6` | 强调浅底、选中行、当前导航项 |
| `--accent-ink` | `#111827` | 浅底上的强调文字 |
| `--accent-line` | `#E2E5E9` | 浅底描边 |
| `--bg` | `#F7F8FA` | 页面画布（中性极浅灰） |
| `--surface` | `#FFFFFF` | 卡片、输入框、消息气泡 |
| `--surface-2` | `#F2F4F5` | 次级面、消息区底、禁用底 |
| `--surface-selected` | `#F3F4F6` | 表格选中行 |
| `--border` | `#E5E8EB` | 分区线、卡片描边 |
| `--border-strong` | `#D0D5DD` | 次要按钮描边 |
| `--input-border` | `#CFD6DD` | 输入框默认描边 |
| `--text` | `#101828` | 正文 |
| `--text-2` | `#475467` | 次要文字、说明 |
| `--text-3` | `#667085` | 占位、时间、元信息 |
| `--success` | `#15803D` | 成功状态圆点与图标 |
| `--online` | `#12B76A` | 在线状态点，只用于圆点 |
| `--warning` | `#B54708` | 需注意状态、等待中 |
| `--warning-soft` | `#FFFAEB` | 等待提示底 |
| `--danger` | `#D92D20` | 危险按钮、超时标记 |
| `--danger-soft` | `#FEF3F2` | 危险提示底 |

规则：

- 强调色为近黑，只标记可交互与当前状态，占屏面积不超过 5%。
- 语义色只用语义；`--online` / `--success` 只出现在圆点与图标，不用于正文或按钮底色。
- 客户侧与工作台共用同一套中性色；`--brand-tint` 只用于登录页品牌区。
- **两侧分叉边界（v7）**：色板、字阶、圆角、描边、阴影、图标、状态语义必须同源，这是「同一家公司」的凭证；图形语言与信息密度允许分叉——客户侧用同心弧（`--wave-*`）承载「被回应」，坐席侧用制图网格（`--grid-line*`）与编号承载「秩序」。两侧不得交换这两套图形语言，也不得在客户侧引入网格、编号或内部阈值术语。

### 2.2 字体与字号

- `--font-sans`：系统无衬线，全站唯一字体（正文、标题、按钮）。
- 不使用衬线体；`--font-serif` 仅作为 `--font-sans` 的别名保留，新增代码不得引用。
- 字号五档，token 与下表同名（`--text-xs` 至 `--text-xl`）。

| 令牌 | 字号 | 用途 |
|---|---|---|
| `text-xs` | 12 | 键位提示、字数、时间、元信息 |
| `text-sm` | 13 | 辅助说明、卡片次要行 |
| `text-base` | 14 | 正文、消息、输入 |
| `text-lg` | 16 | 区块标题、卡片标题 |
| `text-xl` | 20 | 页面标题 |

- 展示字号用受控任意值：登录页主标题 `text-[32px]`、页面标题 `text-2xl`（24）。
- 字重只用 400 / 500 / 600；不使用 700 以上。
- 标题字距 `-0.01em` 至 `-0.02em`；订单号、金额、计数使用 `tabular-nums`。

### 2.3 间距与布局

间距基数 4px，令牌 `--space-1`..`--space-8` 对应 `2 / 4 / 6 / 8 / 12 / 16 / 24 / 32`。禁止 5、7、9、10、14 等非标值；需要微调时改行高或内边距。

| 区域 | 取值（示例，实现取最近令牌） |
|---|---|
| 内容区左右内边距 | 32（<1280 24；<1024 16） |
| 客户侧顶栏高度 | 64 |
| 工作台侧栏宽度 | 232（1024–1279 为 208） |
| 客户消息列最大宽度 | 860 |
| 消息文本最大宽度 | 560 |
| 会话页内容最大宽度 | 1160 |
| 队列表头 / 行高 | 40 / 60 |
| 详情抽屉宽度 | 380（1024–1279 为 340） |
| 消息间距 | 20 |
| 登录卡片最大宽度 | 1040 |

### 2.4 圆角与阴影

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--radius-sm` | 6 | 键位提示、小标签 |
| `--radius-md` | 8 | 小按钮、图标按钮 |
| `--radius-lg` | 10 | 常规按钮、输入框、下拉 |
| `--radius-xl` | 12 | 次级卡片、消息区、提示条 |
| `--radius-2xl` | 16 | 卡片、表格、输入卡、登录卡 |
| `--radius-pill` | 999 | 状态胶囊、头像 |

阴影只用于浮起层：

- 卡片：`--shadow-card`（`0 1px 2px rgba(16, 24, 40, 0.05)`）
- 浮起层：`--shadow-float`（`0 8px 24px -6px rgba(16, 24, 40, 0.12)`）
- 焦点：`--focus-ring`（`0 0 0 3px rgba(17, 24, 39, 0.18)`）
- 字段焦点：`--focus-ring-field`（`0 0 0 1px var(--accent)`）

平面元素不加阴影；卡片用 1px 描边 + 极轻阴影区分层次。

### 2.5 图标

- 通用图标用 `lucide-react`（v1），`size` 为 16 或 20、`strokeWidth` 为 1.6，颜色继承 `currentColor`；lucide 输出的 SVG 自带圆角端点。
- 品牌图形（如 ECHO_MARK 双色弧线）等无对应图标者保留内联 SVG，遵守相同尺寸与颜色规则。
- 不引入第二套图标库、图标字体或远程图标资源。
- 图标必须配文字、`aria-label` 或 `aria-hidden`，不单独承载语义。

### 2.6 样式承载

- 组件样式统一用 Tailwind v4 utility；颜色、字号、圆角、阴影由 `app/globals.css` 的 `@theme` 映射 `tokens.css`，组件只写 utility 类名。
- HeroUI v3 组件自带 BEM 样式按 [frontend.md](../process/frontend.md) FE-CSS-05 引入，不算第二套样式方案；其尺寸、圆角与状态样式只能用 `className` 的 Tailwind utility 约束到本节契约，禁止用全局 `.button` / `.input` 选择器覆盖。
- 字号统一为 `text-xs`（12）、`text-sm`（13）、`text-base`（14）、`text-lg`（16）、`text-xl`（20）五档；标题等展示字号可用 `text-[32px]`、`text-2xl` 一类受控值，不再保留 10.5/11.5/12.5/13.5 等细碎档位。
- 全局 CSS 只保留两类：`app/globals.css`（Tailwind 入口、`@theme`、html/body 基础排版）与 `tokens.css`（令牌）。禁止新增全局选择器。
- 存量 `.module.css` 随页面迁移逐步删除；迁移完成前允许保留，但不得新增。
- 禁止 `!important`、id 选择器、超过 2 层的标签嵌套；动态内联样式只允许数值型 token（如进度宽度），并注释原因。
- 组件内不写颜色/字号字面量，一律用 theme 映射的 utility。

### 2.7 动效

只允许三类，超出即视为违规：

| 类型 | 参数 | 用在哪里 |
|---|---|---|
| 入场 | 240ms `cubic-bezier(0.2, 0, 0, 1)`，`opacity 0→1` + `translateY(6px→0)` | 每页最多一处（首屏或消息区） |
| 状态反馈 | 120ms `ease-out` | hover、active、focus、按钮加载态 |
| 循环 | 等待脉冲 1600ms `ease-in-out infinite`；加载 spinner 900ms `linear infinite` | 等待卡、加载态 |
| 品牌回声 | 3600ms `ease-in-out infinite`，6 条弧线各错开 300ms、由内向外依次亮起，`opacity` 在 0.42↔1 呼吸（基准强度由 `--wave-o-1..6` 给） | 客户侧登录品牌区、欢迎卡；`prefers-reduced-motion` 下静止 |
| 值守心跳 | 1600ms `ease-in-out infinite`，`opacity` 1↔0.35（与等待脉冲同一参数） | 坐席侧登录右上角「值守中」状态灯；`prefers-reduced-motion` 下静止 |

- 禁止：自动轮播、视差、与信息无关的装饰性循环动画（品牌回声、值守心跳与等待脉冲是唯一例外）、超过 300ms 的交互反馈、用 `width/height/top/left` 做布局动画；抽屉与详情只允许 `transform` 200ms。
- `prefers-reduced-motion: reduce`：移除入场与脉冲，状态变化即时生效；spinner 改为静态加载文字。
- 动画期间控件仍可聚焦、可点击；不得用动画隐藏真实状态。

### 2.8 响应式

| 断点 | 客户侧 | 坐席侧 |
|---|---|---|
| ≥1280 | 顶栏 64 + 消息列 860 居中 | 侧栏 232 + 队列全宽；详情为点击行打开的右侧抽屉（380） |
| 1024–1279 | 顶栏 64，消息列自适应 | 侧栏 208；抽屉 340；表格横向滚动 |
| 768–1023 | 顶栏 64，消息列满宽 | 抽屉从右侧滑出；搜索与筛选收在工具栏第二行 |
| <768 | 单列全屏；输入区固定底部；快捷入口两列 | 只读列表（客户/等待/状态三列）+ “请使用桌面端领取”，不提供领取 |

- 2026-11-20 决策：会话详情由桌面常驻栏改为 HeroUI Drawer，所有断点统一「点击行 → 右侧滑出、遮罩 + Esc 关闭、RAC 焦点陷阱」。抽屉与选中解耦：⌘K 可只收起抽屉并聚焦搜索框，J/K 与 Enter 继续操作选中行。队列表格因此获得全宽。
- 768–1279 表格优先横向滚动，不压缩列宽；<768 收敛为只读三列，原因与末条消息在抽屉中展示。
- 移动端只重排现有组件，不新增组件；必须新增时先补本节与组件契约。
- 断点用 `max-width` 与 `min-width` 成对书写，避免断档；不引入 CSS 框架的断点变量。

## 3. 组件契约

每个组件按「结构 → 尺寸 → 状态 → 规则」描述。状态矩阵是验收依据；尺寸取 [tokens.css](tokens.css) 令牌。

### 3.1 品牌栏与顶栏 `brand` / `header`

- 结构（客户聊天）：顶部栏 64——logo（40，圆角 12，深色底）→ 中英文名 → 语言/状态胶囊 → 右侧客户名、结束会话、退出；不再有左侧深色品牌栏。
- 结构（客户侧登录页）：浅灰品牌区（`--brand-tint`）+ 白表单区，整体为一张最大宽 1040、圆角 24、1px 描边的卡片；品牌区含品牌回声（右下角 6 条同心弧，实线与虚线交替，`--wave-o-1..6` 由 9% 加深到 34%，末端实心点，溢出裁切）、状态 chip、40px 主标题与三项服务说明。
- 结构（坐席侧登录页）：同一张卡片的骨架，但品牌区改用制图网格（64px 主格 `--grid-line` + 16px 次格 `--grid-line-2`，右下渐隐）+ 右上角 `CN-SH / 01 · BUILD` 等宽编号与「值守中」状态灯；不放同心弧。内部系统 chip、40px 主标题、三项事实（服务时间 / 8 小时锁定 / 审计留痕）与版本环境标识保持不变。
- 尺寸：顶栏 64；登录品牌区占约 44%，内边距 40；移动端品牌区折叠为顶部横条（logo + 名称），主标题与服务说明隐藏。
- 状态：在线（绿点 + 文案）、非服务时间（灰点 + 留言说明）、会话状态（chip）。
- 规则：顶栏只承载品牌、状态与退出，不放导航；全站不使用衬线标题。

### 3.2 导航与顶栏 `nav` / `topbar`

- 结构（坐席侧）：品牌 → 工作区导航（仅“待接入队列”）→ 坐席卡；取消独立顶栏，标题/刷新与工具栏同属内容区。
- 尺寸：侧栏 232（1024–1279 为 208），导航项 40，图标 16；导航下方为一句话说明（领取后进入会话页回复客户），底部为坐席卡；队列数量只在导航徽标与工具栏 tab 展示，不在侧栏重复概览；搜索位于工具栏。页面标题 20 与状态摘要（`N 个等待 · M 个超时`）同一行。
- 状态：默认、当前（`--accent-soft` 底 + `--accent-ink` 文字）；不再展示未开放项。
- 规则：当前项同一时刻只能有一个；搜索全页仅一处并显示 `⌘K`；通知、在线胶囊与头像不进入队列页顶栏。

### 3.3 按钮 `button`

| 变体 | 底色 | 文字 | 描边 | 用途 |
|---|---|---|---|---|
| `primary` | `--accent` | 白 | 无 | 页面主操作、发送、领取 |
| `secondary` | `--surface` | `--text` | `--border` | 刷新、次要操作 |
| `ghost` | 透明 | `--text-2` | 无 | 顶栏操作、取消 |
| `soft` | `--accent-soft` | `--accent-ink` | 无 | 轻量快捷入口 |
| `danger` | `--danger` | 白 | 无 | 不可撤销操作 |

- 尺寸：`sm` 30、`md` 36、`lg` 44（登录与主 CTA）；内边距 12–20；圆角 `--radius-lg`（10）。
- 状态：默认、悬停（primary 用 90% 不透明度）、焦点（`--focus-ring` 3px 灰环）、禁用（`--surface-2` + `--text-3` + `aria-disabled`）。
- 规则：一个操作区最多一个 `primary`；禁用态必须同时改变无障碍属性，不能只改颜色；主按钮 hover 不再变深（近黑主题下无更深色可退）。

### 3.4 输入框 `field`

- 结构：label → 输入框 → 可选提示；密码框内嵌 32px 图标切换按钮。
- 尺寸：高 44，内边距 0×12，圆角 10；label 13/500。
- 状态：默认（`--input-border` 1px）、聚焦（`--accent` 描边 + `--focus-ring-field` 1px 细环）、禁用、错误（`--danger` 描边 + `role="alert"`）。
- 规则：直接使用 HeroUI field 的描边/背景/焦点样式，组件只统一高度与字号，不再在外层包一层手写描边；错误文案必须与字段关联（`aria-describedby`）；密码切换必须有 `aria-label`。

### 3.5 消息 `message`

- 结构：头像（可选）→ 气泡 → 时间戳；系统消息为居中胶囊，无气泡。
- 尺寸：气泡最大宽 560，内边距 10×14，圆角 `--radius-2xl`（16）；时间 12px 放在气泡下方。
- 客户气泡：`--accent` 底、白字；AI 与坐席气泡：`--surface` 底、`--text` 字、1px `--border` 描边；坐席头像用 `--accent-soft` 底。
- 状态：发送中、已发送、失败（可重试）、转人工后只读。
- 欢迎卡：最大宽 560，与消息气泡同列左对齐；标题 16、说明 14，快捷入口为 32px 软按钮，不做整宽大卡片。
- 规则：客户与坐席的手感靠对齐方向、头像与底色区分，不依赖颜色深浅；时间戳用 `--text-3` + tabular-nums；消息流 `aria-live="polite"`。

### 3.6 等待卡 `handoff`

- 结构：状态圆点 → 标题 → 说明（转人工状态与可继续补充；等待秒数与位次待客户接口扩展，不在前端估算）。
- 尺寸：最大宽 640，内边距 12×16，圆角 `--radius-xl`，底色 `--warning-soft`，描边 `--warning-line`（`#FEDF89`）。
- 状态：排队中（脉冲圆点）、已接通（转 `--success`）、超时（转 `--danger` 并给文案）。
- 规则：等待数字来自服务端；不得用动画速度暗示进度。

### 3.7 队列表格 `queue`

- 结构：工具栏在页面层（不进任何容器）→ 表格为唯一一层圆角描边框：表头 → 行（客户、等待、原因、末条消息、状态、操作）→ 内置页脚；订单数只在详情抽屉展示。
- 分区：页头（标题、状态摘要、Tabs、搜索与筛选）在白色区域，底部一条分隔线；表格与空/错态在灰色内容区，四周 20px 内边距。
- 尺寸：表头 40（滚动吸顶），行 60；列宽 180 / 96 / 140 / 自适应 / 94 / 84；客户列含 32px 头像（Avatar），状态为 7px 圆点 + 文字，领取用 HeroUI Button（`sm`）。
- 等待列：只放 `{m} 分 {ss} 秒`，13（`text-sm`）`tabular-nums`、恒定 `--text`。**不再画轨道**：轨道只是数字的冗余编码，全部超时后满格、区分度归零（2026-11-20 决策）。等待数字不随超时变色，超时只由状态列的圆点表达。
- 状态：默认、悬停（`--surface-muted`）、选中（`--surface-selected` + 左 2px `--accent`）、已超时（**只把状态圆点转 `--danger`，文字保持 `--text-2`**）、加载、空、错误。红色在队列页只出现在这 7px 圆点上，避免一屏多行红字把「待接入」读成「出事了」。
- 规则：超时阈值 5 分钟且必须同时有文字；排序由工具栏控制，默认等待最久，可切最新进入；<768 收敛为只读三列（客户 / 等待 / 状态），原因、末条与领取动作收进抽屉；表格外框只有一层，工具栏与表格之间不得再套 Card；内容区独立滚动，表头吸顶、页脚常驻。

### 3.8 工具栏 `toolbar`

- 结构：页面层工具条——左侧状态 tab（HeroUI `Tabs` 下划线变体，每个 `Tabs.Tab` 内渲染 `Tabs.Indicator`），右侧 `SearchField` / 原因 `Select` / 排序 `Select`。
- 尺寸：tab 行高 36、选中下划线 2px；搜索与两个下拉统一高 32、圆角 10，标签文字在框内（`原因 全部`）；工具条只有底部一条分隔线。
- 规则：搜索必须是 HeroUI `SearchField`（含清空按钮）且全页仅一处；<768 搜索独占一行、两个下拉并排；`Tabs.Indicator` 的选中态来自 tab 级 context，不能放在列表层；筛选变化回到第一页并保留可见条件；空结果与无权限必须区分。

### 3.9 详情抽屉 `detail` / `drawer`

- 载体：HeroUI Drawer（`Drawer.Content placement="right"` + Backdrop + Dialog），所有断点共用，不再有桌面常驻侧栏；焦点陷阱、Esc、遮罩点击关闭由 RAC 提供。
- 结构：客户块 → 三指标（等待 / 原因 / 订单）→ 脱敏末条 → 脱敏提示 → 领取规则 → 主操作；不展示未领取状态下无法打开的“完整上下文”入口与禁用的交接单按钮。
- 尺寸：宽 380（1024–1279 为 340），内边距 24；指标网格 3 列；主按钮高 40；进出场动效用 `--drawer-enter/exit-duration` 压到 200ms；标题左对齐、关闭按钮右置。
- 状态：未领取、领取中、已领取（按钮转“进入会话”）、无权限；<768 隐藏领取按钮，改为“请使用桌面端领取会话”提示。
- 规则：只展示本租户数据；脱敏提示与内容同时出现；领取按钮只在可领取时可用；抽屉打开时背景由 RAC 标记 `aria-hidden`，键盘 J/K/Enter/⌘K 仍为 window 级监听（⌘K 先收起抽屉）。

### 3.10 胶囊与状态 `chip` / `status`

- 尺寸：chip 高 24、字号 12、内边距 0×10、圆角 `--radius-pill`；status 圆点 7。
- 变体：`live`（`--accent-soft` 底 + 绿点）、`warning`（`--warning-soft`）、`danger`（`--danger-soft`）、`neutral`（`--surface-2`）。
- 规则：状态必须文字 + 圆点，颜色只作辅助；一屏同类胶囊不超过两种语义。

### 3.11 空 / 错 / 无权限 `empty` / `error` / `denied`

- 结构：44px 圆形图标 → 标题 → 说明 → 操作。
- 尺寸：空/错/无权限与表格共用内容区面板（全宽、圆角 16、白底、四周 20px 内边距），内容居中；加载态只显示居中 spinner 与“正在同步队列”，不渲染表格骨架。
- 状态：加载（居中加载卡，spinner + 文字，不渲染表格骨架）、空（居中限宽卡，给出下一步）、错误（保留错误码与重试）、无权限（403 与空队列区分）。
- 规则：错误态不得伪装成空态；重试按钮必须可用；空态不写“暂无数据”。

### 3.12 键位提示 `kbd`

- 尺寸：字号 11，内边距 2×6，圆角 `--radius-sm`（6）；HeroUI `Kbd` 底色 `--surface-2`。
- 用法：输入区提示、键盘条、搜索框快捷键；只描述真实存在的快捷键。
- 规则：键盘流必须可发现（常驻提示或 `?` 面板），焦点始终可见。

### 3.13 登录页

- 两套语境共用同一布局：客户侧与坐席侧都是「浅灰品牌区 + 白表单区」的 1040 宽圆角卡片，仅文案、信息与页脚不同。
- 客户侧：在线 chip + 40px 主标题（第二行 `--text-3`）+ 三项服务说明（服务时间、留言、加密），页脚为品牌名；账号由客服开通，不提供自助注册入口。
- 坐席侧：内部系统 chip + 40px 主标题；三项事实（服务时间、8 小时锁定、审计留痕）；底部显示版本号与环境标识（开发/生产）。
- 字段：账号（客户）/ 工号或邮箱（坐席）、密码；密码可见切换必须有无障碍名称。
- 限速明示：客户侧“连续 5 次失败将锁定 15 分钟”；坐席侧“保持登录 8 小时”与审计说明。
- “开发期测试账号”只在开发环境展示；错误提示用 `role="alert"`；移动端品牌区折叠为顶部横条，表单满宽。

### 3.14 归档组件

`confirm`（订单确认卡）随 `001-order-cancel` 规格删除；`suggestion` 并入客户侧欢迎卡的快捷入口；客户侧 72px `rail` 与深色品牌栏均由顶部栏取代。三者不再实现。

### 3.15 分页 `pagination`

- 载体：HeroUI `Pagination`（`Previous` / `Content` / `Item` / `Link` / `Next`），并入表格页脚右侧并保持 `w-auto` 紧凑宽度，不再单独占一行。
- 触发：筛选后条数 > 10 才渲染翻页；≤ 10 时页脚右端改为“领取冲突会刷新队列并提示”。页尺寸固定 10，只切已加载的客户端数据，不伪造服务端分页。
- 状态：上一页/下一页在边界禁用，当前页 `aria-current="page"`；筛选或排序变化回第 1 页；J/K 选中跨页目标时自动翻页。

## 5. 可访问性底线

- 所有交互可用键盘完成，焦点可见，焦点环不得被 `outline: none` 移除。
- 状态用文字表达，颜色仅作辅助；色盲用户应能仅凭文字完成判断。
- 图标按钮必须有无障碍名称。

实测对比度（按 WCAG 2.1 相对亮度公式计算）：

| 组合 | 对比度 | AA 正文 4.5 | AA 非文本 3.0 |
|---|---|---|---|
| 正文 `#101828` / 白 | 17.75 | 通过 | 通过 |
| 次要文字 `#475467` / 白 | 7.69 | 通过 | 通过 |
| 辅助文字 `#667085` / 白 | 4.97 | 通过 | 通过 |
| 白字 / 主色 `#111827` | 17.74 | 通过 | 通过 |
| 白字 / 危险 `#D92D20` | 4.83 | 通过 | 通过 |
| 警告 `#B54708` / 提示底 `#FFFAEB` | 5.20 | 通过 | 通过 |
| 强调文字 `#111827` / 浅底 `#F3F4F6` | 16.12 | 通过 | 通过 |
| 在线点 `#12B76A` / 白 | 2.62 | 不通过 | 不通过 |
| 描边 `#E5E8EB` / 白 | 1.23 | 不通过 | 不通过 |
| 输入描边 `#CFD6DD` / 白 | 1.47 | 不通过 | 不通过 |
| 次级面 `#F2F4F5` / 白 | 1.10 | — | — |

由此产生四条硬约束：

- `--success` / `--online` 只用于圆点和图标，不用于正文；需要成功色文字时改用 `--accent-ink`（16.12:1）。
- 主色为近黑，白字对比 17.74:1；`primary` 按钮的 hover 只能降低不透明度，不能继续加深。
- 输入框与卡片边界对比度低于 3:1，属于已知取舍：靠标签、聚焦环（3px 灰环 + 1px 主色描边）与占位文字补偿。
- 客户气泡（黑底白字）与 AI/坐席气泡（白底描边）靠明暗、方向与头像区分，不依赖微弱色差。

## 6. 明确不做

- 渐变、玻璃拟态、发光边框、粒子或装饰插画；品牌几何图形（同心弧、刻度、标尺）不属于装饰插画，按 2.7 与 3.1 使用。
- 图标字体、远程字体与远程图标资源。
- 表情符号、感叹号堆砌、拟人化语气。
- 多处并存的强调色，或把语义色用于装饰。
