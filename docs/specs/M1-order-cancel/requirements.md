# M1 需求：订单查询与未发货订单取消

- 状态：草案
- 渠道：Web Chat
- 业务系统：Mock OMS
- 关联架构：`docs/architecture/overview.md`

## 1. 目标

让已认证用户能够查询本人订单，并在订单允许时，经明确确认后安全取消未发货订单。

## 2. 用户故事

### US-01 查询订单

作为已认证用户，我可以用订单号查询本人订单，以便确认订单状态。

### US-02 查看最近订单

作为忘记订单号的用户，我可以查看自己有权限访问的最近订单，并选择需要处理的订单。

### US-03 取消符合条件的订单

作为订单尚未发货的用户，我可以请求取消；系统说明影响并在我确认后提交。

### US-04 解释不可取消原因

作为用户，如果订单不符合取消条件，我希望知道原因和下一步，而不是收到模糊失败。

### US-05 安全重试

作为用户，当网络或接口异常时，我希望系统确认取消是否已受理，而不是重复创建申请。

### US-06 人工接管

作为用户，当系统无法确认状态时，我希望问题被转给人工且无需重复描述。

## 3. 功能需求

### FR-01 身份和权限

- 所有请求必须从可信认证上下文获得租户和用户身份。
- 用户只能查询与操作本人有权访问的订单。
- 系统不得通过订单号推断归属或隐式切换租户。

### FR-02 订单查询

- 支持按订单号查询当前用户可见的订单。
- 未提供订单号时，可以列出有限数量的最近订单。
- 查询结果至少包含：订单号、商品摘要、支付/发货状态、可取消性摘要。

### FR-03 歧义处理

- 用户提供的信息无法唯一定位订单时，Agent 必须澄清。
- 澄清前不得执行写操作。

### FR-04 取消资格

- 取消资格必须由服务端规则判断。
- M1 只有在订单存在、属于当前用户、未发货且未取消时允许取消。
- Agent 不得自行覆盖或弱化资格结果。

### FR-05 明确确认

- 提交前必须向用户展示订单和取消影响。
- 用户必须做出明确的确认表达。
- 用户拒绝、改主意或未确认时，系统不得提交。

### FR-06 幂等提交

- 每一次待执行的取消操作具有稳定幂等键。
- 同一用户的重复请求返回同一业务结果。
- 因 UI 重试、网络重试或 Agent 重复调用产生的请求不得创建多个申请。

### FR-07 状态查询与恢复

- 写接口超时后必须使用原幂等键查询状态。
- 恢复流程不得直接假设“失败”或“成功”。
- 持续未知状态需要有限重试，最终转人工。

### FR-08 结果表达

- 最终回复必须准确区分“已提交”“已受理”“已取消”“拒绝”和“处理中/未知”。
- 不得把提交成功表述为订单已经取消。

### FR-09 审计与 Trace

- 每次对话、意图、Tool 调用、确认、状态转换和业务结果必须关联同一 trace。
- 审计记录至少包含操作主体、租户、订单、幂等键摘要、结果和错误分类。

### FR-10 人工接管

- 用户主动要求人工时必须转接。
- 权限异常、结果未知且重试耗尽、业务系统不可用时必须提供转人工路径。
- 转接上下文包含对话摘要、已查询订单、当前 Workflow 状态和待处理步骤。

## 4. 非功能需求

- 安全：服务端授权、最小权限、敏感信息脱敏。
- 一致性：业务状态以 OMS 和持久化 Workflow 记录为准。
- 可靠性：所有外部调用有超时、有限重试和结果查询机制。
- 可测试性：模拟 OMS 支持故障注入。
- 可观测性：关键步骤产生结构化 Trace 和审计事件。
- 可评估性：每个需求至少对应一个验收用例。

## 5. 暂不包含

- 退款申请与退款到账。
- 已发货订单拦截。
- 改地址、换货和补发。
- 真实 OMS、支付或物流系统。
- 商品知识和售前推荐。
- 第三方渠道。

## 6. 业务状态定义

### 订单状态（Mock OMS）

- `PAID_UNFULFILLED`：已支付、未发货，可进入取消判断。
- `FULFILLING`：备货/履约处理中，M1 默认不可取消。
- `SHIPPED`：已发货，M1 不可取消。
- `DELIVERED`：已送达，M1 不可取消。
- `CANCELLED`：已取消。

### 取消任务状态

- `COLLECTING`：正在确认订单和信息。
- `AWAITING_CONFIRMATION`：等待用户明确确认。
- `ELIGIBILITY_REJECTED`：不符合条件，禁止提交。
- `SUBMITTING`：正在提交。
- `SUBMIT_UNKNOWN`：提交结果未知，需要查询。
- `ACCEPTED`：OMS 已受理，但尚未确认最终取消。
- `CANCELLED`：OMS 已确认订单取消。
- `REJECTED`：OMS 拒绝取消。
- `MANUAL_REVIEW`：超出自动处理边界。
