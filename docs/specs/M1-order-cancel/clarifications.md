# M1 澄清清单

- 状态：待答复
- 日期：2026-11-14
- 用途：把 M1 规格里"未写明、实现时必须决定"的事项集中列出。每条给出选项与建议默认值；答复后写回对应规格或 ADR，本条目才关闭。
- 规则：本清单存在未关闭条目时，相关任务保持"未就绪"；答复不得只留在对话中。

## 环境类

### C-01 本地数据库版本与运行方式

- 状态：已关闭
- 答复（2026-11-14）：采用 PostgreSQL 17.12，Homebrew 安装并以 `brew services start postgresql@17` 运行；`localhost:5432`，超级用户为 `ba`，不引入 Docker。已卸载并删除 PostgreSQL 14 及其数据目录。
- 验证：`pg_isready` 返回接受连接；`select version()` 返回 `PostgreSQL 17.12 (Homebrew)`。
- 影响：ADR-0004、T-01 完成标准（已同步移除 `docker-compose.yml`）。

### C-02 数据库迁移与种子数据方式

- 问题：规格只定义表结构草案，未规定迁移工具与种子数据来源。
- 选项：A. Alembic 管理迁移 + 独立 seed 脚本；B. 测试时用建表语句直接初始化，不引入迁移工具。
- 建议：A。AC-09 依赖 `(tenant_id, idempotency_key)` 唯一约束，迁移需要可重放。
- 影响：T-01、T-06。

## 身份与租户类

### C-03 认证方式

- 问题：FR-01 要求"从可信认证上下文获得租户和用户身份"，但未规定用户如何取得身份。
- 选项：A. 开发期用固定测试账号 + 简单会话 Cookie，不做注册登录；B. 接入真实身份提供方。
- 建议：A。M1 要验证的是执行与恢复，不是账号体系；B 会引入外部依赖。
- 影响：FR-01、T-04、AC-02、AC-03。

### C-04 租户模型

- 问题：未定义租户数量与用户归属方式，AC-03 的跨租户用例缺少夹具。
- 选项：A. 固定两个租户，各带两个用户；B. 单一租户，AC-03 用参数注入模拟。
- 建议：A。B 会让"跨租户"退化成"参数非法"，验证不到真实越权路径。
- 影响：AC-03、AC-15、T-04。

## 数据夹具类

### C-05 Mock OMS 预置订单

- 问题：未定义夹具订单覆盖哪些状态与归属。
- 建议：每租户 4 单，覆盖 `PAID_UNFULFILLED`、`FULFILLING`、`SHIPPED`、`CANCELLED` 各一单，另加一单属于其他用户的订单。
- 影响：AC-01、AC-02、AC-07。

## 时间参数类

### C-06 确认超时时长

- 问题：设计写"超过可配置时长转入 `ABANDONED`"，未给数值。
- 建议：默认 30 分钟，通过环境变量覆盖；测试用 1 秒。
- 影响：AC-19。

### C-07 重试次数与间隔

- 问题：AC-12 要求"有限重试"，未给具体次数与退避策略。
- 建议：最多 3 次，指数退避 1s / 2s / 4s；耗尽转 `MANUAL_REVIEW`。
- 影响：AC-12。

### C-08 外部调用超时阈值

- 问题：AC-10 的"超时"需要一个明确阈值才能构造测试。
- 建议：单次 OMS 调用 2 秒超时；Mock OMS 可注入超过该值的延迟。
- 影响：AC-10、AC-11。

## 模型与可观测类

### C-09 模型供应商与结构化输出

- 问题：design §10 遗留项；T-09 依赖它。
- 选项：A. 供应商可替换的接口 + 首个实现用单一供应商；B. 直接绑定某家 SDK。
- 建议：A。ADR-0001 已定"业务状态不放在 Agent 框架内"，接口越薄越容易替换。
- 影响：T-09。

### C-10 Trace 存储与导出

- 问题：design §10 遗留项。
- 建议：M1 只要求 `trace_id` 贯穿结构化日志，导出后端推迟到 T-12 再定。
- 影响：AC-17。

### C-11 审计脱敏字段清单

- 问题：AC-18 要求"不记录超范围个人信息"，但没有清单就无法判定。
- 建议：明确禁止记录：令牌、密码、完整卡号、完整手机号、完整地址；允许记录：订单号、用户 ID、状态、错误码。
- 影响：AC-18、T-12。

## 交互类

### C-12 刷新后的会话恢复范围

- 问题：`ui.md` 要求刷新后依据后端状态恢复界面，但未定义恢复到什么粒度。
- 选项：A. 恢复最近一条任务状态与消息列表；B. 刷新即新会话，仅恢复进行中的任务。
- 建议：A。用户取消到一半刷新，应看到同一任务而不是重来。
- 影响：AC-04、AC-05、T-10。
