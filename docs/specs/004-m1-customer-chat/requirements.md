# 004 客户聊天实现规格

- 状态：草案
- 日期：2026-11-16
- 级别：T3（客户登录、订单归属、客户侧限速与审计）
- 依据：[003 M1 验收/契约](../003-m1-customer-service-loop/design.md)、[003 requirements](../003-m1-customer-service-loop/requirements.md)、[ADR-0006](../../adr/0006-customer-login.md)
- AC：**不新增 AC**；验收引用 003 的 AC-30、AC-31、AC-32、AC-33、AC-35、AC-36、AC-44、AC-45、AC-46、AC-47、AC-49，以及 AC-48 客户路径
- 范围：客户登录/session、客户聊天、订单列表/详情、AI 回复、转人工创建、客户 Web Chat、客户侧审计/限速/保留
- 不范围：员工登录/工作台/队列/接管、取消确认（005/006）；客户自助注册/OTP/MFA
- 演示/验收：客户 A 登录→看自己订单→AI 回复→转人工；客户 B 登录→独立订单/会话→第二条队列

## 1. 目标

交付客户侧完整切片：客户登录后只看到自己的会话与订单，AI 能回复和调用订单 Tool，需要时生成交接单进入队列。M1 的客户侧行为在本 spec 收口，但 M1 整体出口仍由 003 的端到端验收决定。

## 2. 非目标

- 客户取消（006）；取消确认/30min 到期不在本 spec。
- 员工登录、工作台、队列领取/接管/回复/关闭（005）。
- 客户自助注册、找回密码、OTP/MFA、账号管理界面。
- 历史会话列表；M1 只恢复唯一未关闭会话。
- 知识库/RAG/FAQ。

## 3. 用户故事

### US-004-1 客户登录与恢复

作为客户，我用预置账号登录，进入自己的未关闭会话；刷新/换设备重新登录能接上。
- 验收：AC-30、AC-49。

### US-004-2 客户看自己的订单

作为客户，我只看到本人账号名下、同租户订单；他人/跨租户订单不可见。
- 验收：AC-32、AC-33。

### US-004-3 客户与 AI 对话

作为客户，我发消息后得到 AI 回复；AI 可以在授权范围内查单/解释；模型超时或不可用会转人工，不静默失败。
- 验收：AC-31、AC-35、AC-36。

### US-004-4 客户转人工并排队

作为客户，我可以显式转人工；AI 低置信/高风险/模型不可用/Workflow 未知时也会转人工；没有坐席领取时我看到排队，不丢会话。
- 验收：AC-35、AC-36、AC-44。

## 4. 功能需求（FR → 003 AC）

| ID | 需求 | 003 AC |
|---|---|---|
| FR-004-01 | 客户用预置账号/密码登录，建立 24h 绝对 session；登录恢复唯一未关闭会话；错误 401/超限 429；登出撤销。 | AC-30、AC-49 |
| FR-004-02 | 客户只能看到本人账号、同租户订单列表；列表不含他人订单。 | AC-32 |
| FR-004-03 | 客户查询本人订单详情返回 6.8 客户订单字段；他人/跨租户 404；未登录 401。 | AC-33 |
| FR-004-04 | 客户发消息持久化并触发 AI；模型 10s 超时/不可用生成 `MODEL_UNAVAILABLE` 交接单。 | AC-31、AC-35 |
| FR-004-05 | AI 订单 Tool 使用客户 `OmsAccess(tenant, user_id=customer.oms_user_id)`；不得跨客户。 | AC-32、AC-33 |
| FR-004-06 | 显式转人工、低置信、高风险、Workflow 未知按 6.1 优先级创建交接单；交接单含客户账号。 | AC-35、AC-36 |
| FR-004-07 | 交接单摘要≤500 字、最近 20 条且≤4000 字；客户账号/订单/AI 轨迹/待办/原因齐全并脱敏。 | AC-36 |
| FR-004-08 | 无坐席领取时交接单 `QUEUED` 持久化；客户看到排队；重新登录恢复该会话。 | AC-44 |
| FR-004-09 | 客户登录/消息按 6.6 限速；客户侧审计事件落库；客户 session/消息/交接单按 6.5 保留。 | AC-45、AC-46、AC-47 |
| FR-004-10 | 客户 Web Chat 有两个入口：登录/恢复、聊天/订单/转人工/排队状态；3s 轮询。 | AC-30、AC-31、AC-35、AC-44 |
| FR-004-11 | 场景评测覆盖客户 A 全链路与 B 隔离；不覆盖员工工作台/取消。 | AC-48 客户路径 |

## 5. 失败与错误

- 登录失败统一 401；超限 429；不泄露账号存在性。
- 订单越权 404；未登录 401。
- 模型失败转人工；消息不丢半条。
- 无坐席：`QUEUED`，客户看到等待；不返回“已接入”。
- 审计写失败：变更 503，不提交。
- 限速先于业务副作用。

| 转人工/排队 | `service_handoffs` + 队列状态 + 客户轮询 |
| 审计/限速/保留 | `service_audit_events` + `service_rate_limit_buckets` + 清理 worker |
| 客户前端 | `apps/chat` 组件/轮询/失败路径 |
