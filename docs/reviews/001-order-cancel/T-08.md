通过。四轮评审：不通过 → 不通过 → 有条件通过 → 通过。

## 第一轮：不通过

| 问题 | 处理 |
|---|---|
| 越权/不存在订单 500 | 路由捕获 `GatewayError` 并映射状态码 |
| `MANUAL_REVIEW` 不可达 | 恢复重试耗尽后转人工 |
| 超时后台写与查询竞争 | 恢复轮询 + `asyncio.to_thread` |
| `SUBMITTING` 悬挂 | `get()` 触发恢复 |
| 下游非法响应 500 | 网关校验 Response 契约 |
| SQL 仓储零测试 | 补真实 Postgres 仓储用例 |
| 重复确认 409 | 终态返回当前结果（幂等） |
| `trace_id` 用 user_id | 每请求 UUID |

## 第二轮：不通过

| 问题 | 处理 |
|---|---|
| OMS `UNKNOWN` 不重试 | 视为失败尝试，退避后重试，耗尽转人工 |
| 提交成功被读失败降级 | 提交即受理，读失败保持 `ACCEPTED` |
| 无版本锁/联合唯一/设计字段 | `version` 乐观锁、联合唯一、`conversation_id`/`last_error_code`/`oms_request_id` |
| 退避小于设计 | 默认 1s，指数递增 |
| 响应契约分支无测试 | 补非法响应用例 |
| 有效期测试恒真 | 假时钟断言 30 分钟 |
| `COLLECTING` 未创建 | 先落收集态再迁移 |
| 查询路径阻塞事件循环 | `asyncio.to_thread` |

## 第三轮：有条件通过

| 问题 | 处理 |
|---|---|
| `TaskConflict` 未映射 | 路由映射 409 |
| ORM 全局唯一与迁移不一致 | 改为联合唯一约束 |
| `ACCEPTED -> CANCELLED` 不可达 | 受理后与查询时“只推进不降级”刷新 |
| 设计字段未写入 | `conversation_id` 透传、错误码记录 |
| 测试慢/旁路构造 | 退避 0.01s，真实提交构造状态 |

## 第四轮：通过

| 问题 | 处理 |
|---|---|
