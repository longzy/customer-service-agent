## 遗留（非阻断）

1. `_finish` 以任务用户身份重建 `Identity`，`actor_type` 恒为 `user`；启动恢复/超时转换的审计操作主体失真（FR-09）。接受为后续项。
2. `recover_pending` 仅 catch `TaskConflict`；`main.lifespan` 的兜底 `except Exception` 会把 `TraceSinkError` 变成整批恢复中止并只记 exception，与 design 8.3 “逐任务 warning” 不完全一致。
3. mutation 不含 `observability`/`audit`，且只跑 unit；不能作为 AC-17/18 核心的突变证据。
4. 登录/会话日志无显式测试；`log_event` 目前仅 `/message` 一条，`logger.warning/exception` 仍是非 JSON 文本（严格按 design 8.4 读法）。
5. `test_取消审计失败` 的清理按 `order_id=ORD-10001` 删除、无租户过滤，存在测试库污染风险。
6. `CancellationTask.trace_id` 仍保留 `uuid4` 默认；当前 SQL 映射均已显式赋值，建议后续改为必填或移除默认以防回归。
7. `/message` 响应经 `asdict(reply)` 新增 `validation`（`replaced`/`mismatch`）字段；无敏感数据，属接口面新增，前端不展示。
