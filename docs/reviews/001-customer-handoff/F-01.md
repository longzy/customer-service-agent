## Spec 轴

初始发现与整改：

| 发现 | 结论 |
|---|---|
| 5xx 未走统一错误封套 | 已解决：`Exception` 全局处理器返回 `INTERNAL_ERROR` 封套，含 `X-Request-ID`；依赖故障测试覆盖 |

| 全局 422 封套改写旧 M1-P 路由 | 已解决：仅 `/customer/*` 使用封套；旧路由 `{"detail": ...}` 有回归断言 |
| 跨客户读接口未在 plan 表 | 已解决：plan 3.3.3 已回写 `GET /customer/conversations/{id}` |
| `after_id` 恒 0 | 接受：F-01 无消息表，F-02 接入 `service_messages` 后改为真实游标并补断言 |
