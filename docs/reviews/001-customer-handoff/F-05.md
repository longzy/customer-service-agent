## 逐 AC

AC-34 逐项覆盖：

| AC-34 判定点 | 证据 |
|---|---|
| 2 个坐席种子账号 | 种子脚本用例：`agent_1`/`agent_2`，角色 `agent`，重复执行仍 2 行 |
| 8h 绝对 session | 8h 内 200；8h 整点 `SESSION_EXPIRED`；刷新不滑动 |
| 登录轮换撤销旧 session | 同员工旧 token 401；另一坐席 token 不受影响 |
| 登出 401 与幂等 | DELETE 204、清 cookie、旧 token 401；再次 DELETE 204 |
| 错误密码/未知账号统一 401 | 同一 `AUTH_FAILED` 响应；空字段/越权字段 422 |
| 超限 429 | 连续 5 次失败后第 6 次 429 `RATE_LIMITED` + `Retry-After` |
| 非 agent 403 | 登录 403 且不建 session；登录后角色降级立即 403；浏览器走查通过 |
| 未登录 401 | `/workspace/session`、`/workspace/conversations/{id}` |
| 未领取/他人/跨租户 404 | 4 种 404 响应一致；本人已分配会话 200 |
| 生产 cookie Secure | 生产 `Settings` 下 `esid` 带 `Secure` |
| `M1_ENABLED=false` | workspace 路由不挂载，返回 404 |
| 前端刷新/登出 | vitest 6 条；浏览器登录→刷新 `/queue`→退出回 `/login` |
